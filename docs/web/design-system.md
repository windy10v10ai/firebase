# 网站视觉规范：配色、按钮与可点击元素

> 本文是网站长期有效的视觉规范：颜色怎么分工、取什么值，按钮怎么选，能点的东西长什么样。只在规范变更时更新，不因批次完成而增删。写代码时照着做的规约见 [web/CLAUDE.md](../../web/CLAUDE.md)「可点击元素」「颜色」「按钮」。
>
> 取值的真相源是 `web/app/globals.css` 的 `@theme`，本文与它不一致时以代码为准，并回来改本文。规范的样子看开发环境的规范页 `/design-system`：它直接用 token 和真实组件渲染，生产环境不开放，本文不放规范截图。
>
> 本文已按网站改版更新，代码在改版的几个 PR 里陆续跟上，进度见 [docs/design/web/redesign.md](../design/web/redesign.md)；跟上之前以本文为准。

## 一句话结论

**每件事有固定的颜色。** 勇士用紫、会员用金；「能点」由网站自己的主色（余烬橙）表达，橙色只上按钮与标记，不写字；每个功能有自己的图标色；第三方平台的品牌色只留在它们自己的标识上。按钮颜色回答「点了花什么」：网站自己的操作用主按钮，花积分用与游戏一致的游戏按钮。

## 1. 配色分工

| 颜色 | 管什么 | 不用在 |
|------|------|------|
| 中性灰 | 底色、卡片、分隔线、正文、链接文字、次按钮 | — |
| 网站主色 | 主按钮、强调按钮；它的标记档管当前页标记、可点击卡片的悬停描边、焦点框、转圈 | 文字（含链接）、数值、标题 |
| 勇士紫 | 勇士等级与积分、属性卡进度条、花勇士积分或与游戏同名操作的按钮、勇士相关标题 | 交互反馈、通用按钮 |
| 会员金 | 会员等级与积分、皇冠、花会员积分的按钮、会员相关标题；排行榜第 1 名的名次胶囊 | 交互反馈、通用按钮 |
| 功能色 | 各功能的图标与图标底块 | 数值、按钮、标题、箭头 |
| 品牌色 | 第三方平台自己的标识 | 按钮、描边、悬停、数值 |
| 状态色 | 成功、危险、警告 | 装饰 |

**为什么这样分**：紫色曾经同时是勇士积分色、全站交互色和默认按钮色，每一页都满是紫，玩家分不清哪块紫在说积分、哪块在说「能点」。每件事固定用一种颜色，交互不借用货币色，含义才读得出来。

**为什么主色是余烬橙**：纯黑底配冷色太单调，暖橙与首页首屏的游戏封面图是一套色调，网站看起来更有活力。

## 2. 取值

### 中性与货币

| token | 取值 | 用途 |
|------|------|------|
| `--color-surface` | `#101012` | 页面底色 |
| `--color-panel` | `#18181b` | 卡片、头部 |
| `--color-panel-soft` / `--color-control` | `#1f1f23` | 嵌入块、控件底 |
| `--color-control-hover` / `--color-panel-raised` | `#27272b` | 控件悬停 / 浮层标题块 |
| `--color-control-active` | `#19191c` | 次按钮、文字按钮按下 |
| `--color-line` | `#2e2e33` | 描边与分隔线 |
| `--color-line-strong` | `#46464e` | 浮层描边、次按钮悬停描边、链接下划线 |
| `--color-heading` / `--color-content` / `--color-muted` | `#fafafa` / `#d4d4d8` / `#8b8b93` | 标题 / 正文 / 次要 |
| `--color-faint` | `#5d5d66` | 禁用文字、数值分隔符 |
| `--color-season` / `-strong` | `#a874ea` / `#9b5de0` | 勇士文字 / 填充；`-soft`、`-border` 为 12%、40% 透明 |
| `--color-season-light` | `#c4a3f3` | 紫色底块上的浅紫文字，如属性页的「已满级」 |
| `--color-member` / `-strong` | `#e0caa5` / `#daa520` | 会员数值 / 标题与填充；`-soft`、`-border` 为 11%、40% 透明 |

中性色是带一点灰的炭黑，不是纯黑：纯黑底上的卡片与底色分不开层次。

勇士紫取自游戏的 season point 色，金取自游戏的 `@color-gold` 与 `@color-gold-muted`。

`--color-dota-*`（伤害类型色、魔法消耗色）是游戏语义色，只用在技能提示框，取值与用法见 [ability-tooltip.md](ability-tooltip.md) 第 2 节。`--color-game-*` 是物品提示框照游戏内物品提示的整套底色与文字色，只用在物品的悬浮提示与详情弹窗，取值与用法见 [ability-tooltip.md](ability-tooltip.md) 第 3 节「物品」。

### 首页的暖色首屏

只有首页换底色，其余页面都用上面的中性底与实心卡片。

| 位置 | 取值 |
|------|------|
| 首屏底色 | `#120c0a`，往下渐变到 `surface` |
| 首页卡片底 / 描边 | `rgba(255, 255, 255, 0.035)` / `rgba(255, 255, 255, 0.07)`，半透明，透出背后的渐变 |
| 首屏面板 | 底 `rgba(34, 20, 15, 0.55)` 加背景模糊，描边 `rgba(255, 214, 186, 0.14)`，顶边内高光 `rgba(255, 214, 186, 0.22)` |
| 未登录面板的示例卡 | 虚线描边 `rgba(255, 214, 186, 0.32)` |
| 压在图上的控件（头部的语言、登录、菜单，首屏的「获得地图」「下载启动器」） | 底 `rgba(255, 255, 255, 0.06)`，悬停 `0.12`；头部控件描边 `0.14`，首屏按钮描边 `0.2` |

- **暖色只留在首屏**：整页都偏红会看累，往下过渡回中性，和其他页面接上
- 首屏背后是游戏封面图（去掉标题文字的版本），手机上裁到 Dota 标志那一块
- **压在图上的控件用半透明白底**：实心炭灰在图上像一块补丁；只在首页顶部头部透明时换，滚动后回到普通样子
- **首屏的「获得地图」「下载启动器」是半透明次按钮**：这一屏的强调按钮留给登录或签到
- **已登录面板下方预留签到行的高度**：签到行要等数据回来、且只有有效会员才有，非会员与过期会员不显示也不换内容；预留后下方的主要页面不随加载结果跳动
- **未登录面板的示例卡用虚线框加「示例」标签**：要一眼看出不是自己的数据，免得以为已经登录、等级不对
- **启动方式卡的图标与底块用主色橙**，是功能色规则的例外：它和会员卡是首屏下方仅有的两张推荐卡，要比中性入口醒目；头部菜单里的「启动游戏」仍是中性灰

### 网站主色（余烬橙）

| token | 取值 | 用途 |
|------|------|------|
| `--color-primary-from` / `-to` | `#cf8048` → `#b8662f` | 主按钮底，从上到下渐变 |
| `--color-primary-hover-from` / `-hover-to` | `#d98e58` → `#c4733d` | 主按钮悬停 |
| `--color-primary-active` | `#b8662f` | 主按钮按下，纯色 |
| `--color-primary-border` / `-border-bottom` | `#dc9060` / `#8a4420` | 主按钮描边 / 底边 |
| `--color-primary-text` | `#1a0c05` | 主按钮与强调按钮的黑字 |
| `--color-cta` / `-hover` / `-active` | `#f07a2a` / `#f58a42` / `#e06d20` | 强调按钮底 |
| `--color-cta-border` / `-glow` | `#ff9a55` / `rgba(240, 122, 42, 0.45)` | 强调按钮描边 / 下方淡光晕 |
| `--color-link` / `-hover` | `#e07a3c` / `#f0955a` | 标记档：当前页标记、焦点框、转圈 |
| `--color-link-border` | `rgba(224, 122, 60, 0.5)` | 可点击卡片悬停描边 |

- **主按钮是杏色渐变配黑字**：亮橙实底太刺眼，白字压在橙上也发亮；杏色更安静，按钮多的页面也不吵
- **扁平，不做厚边**：层次只靠顶部一道 20% 白的内高光和深一档的底边，网站整体是扁平风格
- **强调按钮是亮橙实底配黑字、800 粗**，比主按钮更抢眼，只给一屏里最想让人点的那一个
- **橙色不写字**：橙字压在深底上发脏，还会和按钮抢视线。链接的写法见第 4 节
- token 名叫 `link`，但只用于标记，不上文字

### 功能色

| 功能 | token | 取值 | 图标 |
|------|------|------|------|
| 属性加点 | `--color-feature-property` | 引用 `--color-season`（`#a874ea`） | lucide `ChartNoAxesColumn`（柱状图） |
| 英雄觉醒 | `--color-feature-awaken` | `#dd53e7` | lucide `Sparkles` |
| 每日任务 | `--color-feature-daily` | `#04bbc3` | — |
| 技能与物品 | `--color-feature-wiki` | `#7ca2f6` | lucide `BookOpen` |
| 预留 | 上线时新增 | `#3fbe90` | — |

每个都有同色 12% 透明的 `-soft`，给图标底块用。对 `--color-panel` 的对比度都在 4.5 : 1 以上。

- **只上图标与图标底块**，数值、按钮、标题、箭头不跟；首页卡片、头部菜单、个人主页入口卡三处同色、同图标
- **「即将上线」靠虚线描边、灰标题与标签表达**，图标颜色不变
- 属性用勇士紫、觉醒参考游戏的 `#d000ff`，与游戏内这两个功能的主色一致。觉醒不直接用 `#d000ff`：它离勇士紫只差 15° 色相、饱和度拉满，缩成图标后两者都读成紫
- 技能与物品用蓝，不用橙：橙已经是网站主色
- **扩展顺序**：新功能取预留色，它离成功绿约 20°；用完后新功能用中性图标，不再往色环里挤
- 带含义的色相不做功能色：主色橙、会员金、成功绿、危险红。不属于某个功能的入口（如个人主页）用中性灰

### 品牌色

| 平台 | token | 取值 | 与站内哪个颜色同色系 |
|------|------|------|------|
| 爱发电 | `--color-afdian` | `#946ce6` | 勇士紫 |
| Ko-fi | `--color-kofi` | `#29abe0` | 每日任务青、技能与物品蓝 |
| 支付宝 | `--color-alipay` | `#1677ff` | 技能与物品蓝 |
| Stripe | `--color-stripe`，文字用 `--color-stripe-text` | `#635bff` / `#8f89ff` | 技能与物品蓝、勇士紫之间 |
| 微信支付（接入时新增） | — | `#07c160` | 成功绿 |
- **能上的位置**：平台名、品牌图标、二维码外框、正文里指向该平台的链接、平台自己的页面标题（如激活页）
- **不能上的位置**：按钮底色、卡片描边、悬停、数值（会员页购买区例外，见下）
- 理由：品牌色都和站内有含义的颜色同色系，上到按钮上，玩家分不清颜色在说「哪个平台」还是「积分 / 能点 / 成功」。同屏多个平台时靠图标与平台名区分
- 例外：平台 SDK 自己渲染、且规定了外观的按钮（如 PayPal 智能按钮），照平台规定
- 例外：会员页的购买区按付款平台切换，选中的平台标签描边、说明条底色与描边、档位卡顶边 3px 顶条与悬停描边用该平台的品牌色。此时整块区域只属于一个平台，颜色只回答「现在用哪家付」；悬停若用主色橙，会和品牌色顶条撞色。卡片底色、文字与静止时的其余描边仍是中性色，折扣仍用 `discount`
- 品牌原色压在深色底上做文字不到 4.5:1 时，另加一档浅色专给文字用，图标、描边、顶条仍用原色
- 新增平台时加 token，并在上表登记它和谁同色系

### 状态色

| token | 取值 | 用途 |
|------|------|------|
| `--color-success` | `#7fd47f` | 成功、点赞、「推荐」胶囊 |
| `--color-danger` | `#e87d7d` | 危险、举报、危险按钮 |
| `--color-warning` | `#f5a623` | 警告 |
| `--color-discount` | `#ff6b6b` | 折扣标签（如随机觉醒卡的「-50%」），不上按钮与正文 |

折扣不借用 `danger`：折扣不是危险，而且要和绿色的「限免」标签一眼分开。折扣标签与限免标签同形：1px 描边加同色文字、`bg-black/60`、11px 粗体。

近期战绩的 K / D / A 是这两个颜色的第二处用法：击杀绿、死亡红、助攻用正文白，斜杠压到 `--color-faint`。三段含义固定，不按这局打得好不好变色——那是替玩家下判断。同一行最左端 3px 的胜负色条用的是同两个颜色，一个贴边、一个在行中间，读不混。

两种标签跟在卡片顶部的名字右边，名字居中、左边留出等宽的空位。名字加两侧标签放不下时，名字独占第一行，标签退到第二行右侧，顶部压暗跟着加深；名字不截断。这与游戏的觉醒卡一致。

「推荐」用绿色胶囊：全圆角、`success` 40% 描边、10% 底、同色文字，启动器对比表与会员页的付款标签共用。它说的是「选这个省事」，和成功同一种绿；压在别的描边上时外层垫一层不透明底。


## 3. 按钮

### 选哪种

**按钮颜色回答「点了花什么」，不回答「这一页讲什么」。**

| 操作 | 按钮 |
|------|------|
| 花勇士积分，或与游戏里是同一个操作（加点、觉醒） | 游戏紫 `.btn-season`；暂存、还没提交的一步用 `.btn-season-outline` |
| 花会员积分 | 游戏金 `.btn-member` |
| 一屏里最想让人点的那一个（首页首屏的登录与签到、`/launch` 的下载） | 强调按钮 `.btn-cta` |
| 提交、重试、跳转、去外部平台订阅或付款 | 主按钮 `.btn-primary` |
| 取消、次要操作 | 次按钮 `.btn-secondary` |
| 与主按钮并排的返回、跳过 | 文字按钮 `.btn-ghost` |
| 清空、重置这类撤不回的入口 | 危险按钮 `.btn-danger` |
| 登录类的第三方入口 | 次按钮外观加品牌图标 |

- **每屏最多一个主按钮或强调按钮**：强调按钮就是那一屏的主按钮，只是更醒目；大多数页面用主按钮，只有真要把玩家往一个动作上推时才换强调按钮
- 「会员相关就用金」不成立：会员页、激活页都跟会员有关，全用金只是把紫色的问题换成金色
- **头部常驻的 Steam 登录用次按钮外观加单色 Steam 图标，不做专属设计**：Steam 的深色和网站底色几乎一样，做出来也认不出，认出是 Steam 靠图标；登录入口每页都在，用主色会和每一页自己的主操作抢。首页首屏的登录是那一屏唯一的主操作，用强调按钮加 Steam 图标

### 网站按钮

| 变体 | 默认 | 悬停 | 按下 |
|------|------|------|------|
| 主按钮 | 底 `primary-from` → `primary-to` 渐变、边 `primary-border`、底边 `primary-border-bottom`、顶部内高光、黑字 `primary-text` | 底 `primary-hover-from` → `primary-hover-to` | 底 `primary-active` 纯色、无高光 |
| 强调按钮 | 底 `cta`、边 `cta-border`、黑字 800、下方淡光晕 `cta-glow` | 底 `cta-hover` | 底 `cta-active`、无光晕 |
| 次按钮 | 底 `control`、边 `line`、字 `content` | 底 `control-hover`、边 `line-strong`、字 `heading` | 底 `control-active` |
| 文字按钮 | 透明、字 `content` | 底 `panel-soft`、字 `heading` | 底 `control-active` |
| 危险按钮 | 边 `danger` 50%、底 `danger` 8%、字 `danger` | 底 `danger` 15% | 底 `danger` 22% |

共同规格：14px / 700（强调按钮 800）、无文字阴影、圆角 7px。高度手机与平板 44px、电脑 40px；页面里唯一的入口（登录横幅、登录面板）56px；头部控件 36px。焦点框 2px 标记档橙、偏移 2px。禁用一律灰底 `panel-soft`、灰字 `faint`，不带渐变与光晕。

**请求进行中**：按钮内 16px 转圈，文字换成进行时，同时禁用；不盖整页遮罩。

取值照搬游戏仓库 `src/panorama/react/shared/styles/buttons.less`，**不改**，属性、觉醒页要与游戏内同名操作长得一样。

| `.btn-season` | `linear-gradient(90deg, #4f48b2, #0f033a)` | `#7a6fd0` | 白字 800，`text-shadow: 0 1px 4px rgba(0,0,0,0.53)` |

## 4. 可点击元素

- **能点的一律手型光标**，由 `globals.css` base 层统一给所有可用的 `<button>` 与 `[role=button]`；禁用的按钮是禁止符号。Tailwind 4 的 preflight 不给按钮手型，不补的话凡是按钮做的控件都是箭头
- **悬停描边随归属**：属于勇士的入口描紫边，属于会员的描金边，其余用主色标记档
- 属性页的等级框这类嵌在卡片里的小入口，只变描边在深色底上看不出，悬停同时提亮底色与箭头

### 可点击卡片

全站能点的卡片用同一个模板，从左到右：

| 部分 | 规格 |
|------|------|
| 图标底块 | 功能色图标加同色 `-soft` 底；不属于某个功能的用中性灰 |
| 标题与说明 | 标题 `heading`，说明 `muted` |
| 操作胶囊（可选） | 高 32px、全圆角、1px `capsule-border`（`rgba(255, 255, 255, 0.18)`）描边、13px `capsule-text`（`#d6d2cf`）字，写这张卡点进去做什么；手机上不显示 |
| 圆形箭头 | 直径 36px、1px `arrow-border`（`rgba(255, 255, 255, 0.16)`）描边，里面是 `muted` 的右箭头 |

- **操作文字放进胶囊**：橙色字难看，浅色粗字又和标题重复，胶囊让它读成「按钮」而不是第二个标题
- **说明较长的宽卡把胶囊放到说明下面**（如首页的会员卡、启动方式卡）：放在右侧会把说明挤成好几行
- **列表里整行是链接时只放右箭头**（`muted`），不套圆框；悬停要有看得见的变化；不能点的不放箭头，否则玩家点了没反应

### 文字链接

- **正文里的链接用标题色加下划线**，下划线 `line-strong`，悬停时下划线提亮到 `heading`：靠下划线认出是链接，不靠颜色
- **导航类链接（页头、页脚、返回）静止是中性色，悬停提亮到 `heading`**
### 头部与菜单

- **头部底色 `panel`、底边 `line`，吸顶**；首页滚动距离很小时底色与底边透明，控件换成半透明底（见「首页的暖色首屏」），往下滚换回实心；菜单打开时也是实心，与不透明的菜单连成一块。菜单开合用短促的淡入与下移，不做大幅度动画
- **菜单项的图标放进 28px 小底块**，底色用该功能的 `-soft`，中性项用 `icon-tile`，与可点击卡片的图标底块一致
- 尺寸见 web/CLAUDE.md「断点」：头部控件 `lg` 以下 44px、`lg` 起 36px；菜单行不低于 44px

### 当前页标记

头部横排导航项底下一条主色标记档的下条，菜单行左侧一条同色竖条。三条规则：

- **当前页悬停无变化**：它已经是终点，点了还在这一页。当前页就等于常驻的悬停态
- **汉堡按钮不标当前页**：它是「打开菜单」的开关，不是导航项；手机上它是唯一入口，永远高亮等于永远不高亮
- **窄屏的位置提示只在菜单里**：下条长在横排上，而窄屏把横排整体收起了。收起时不补页面名——375 那一行只剩 13px 余量，而且页面标题本来就在头部正下方第一行

悬停只动亮度不动色相，时长 0.15s `ease-out`；`prefers-reduced-motion: reduce` 下全部归零。

### 提示与说明

需要额外解释的地方统一用说明弹层这一个控件，不在各处散写原生 `title`：**有鼠标时悬停即展开，触屏靠点击，键盘聚焦也展开**，点击外部或 Esc 收起。触发元素既可以是问号图标，也可以是被解释的那个东西自己——列表头的游戏图标、缩写成 `LH`、`Слож.` 的列名都直接当触发元素，命中区撑满整格，不要只让 15px 的图标可悬停。

内容一两个词时弹层按内容收宽，成段的说明用固定宽度。

原生 `title` 只剩两种用途：揭示被 `truncate` 截断的文字，以及纯装饰图片的替代文本。它在触屏上完全不出现，延迟也不可控，不拿来承载玩家需要读到的信息。

## 5. 等待与失败

- **加载与提交不盖整页遮罩**。遮罩把头部和底部一起盖住，画面上只剩一个转圈，玩家不知道在等什么
- **等待超过几秒就把「在等什么、等了多久」写出来**，失败时给一块可截图的排查信息（卡在哪一步、错误码与细分原因、耗时、时间、玩家 ID）。玩家往往在转圈时就关掉页面，排查信息只在失败页出现是不够的

## 6. 游戏语义色的破例

**紫与金只表示勇士与会员两套货币**，这条有一个例外：近期战绩里的英雄等级圈用暗金 `--color-hero-level` `#e7d291`，描边 `--color-hero-level-border`。

取值照搬游戏结算界面的 `#HeroLevelLabel`（27px 正圆、1px 描边、字距 1px），网站按行高缩到 23px。破例的理由是它整体搬自游戏——玩家读到的是「游戏里那个等级圈」，不是会员。会员金是 `#daa520`，这个明显更浅，摆在一起分得出。

**只用在这一处。** 别处要金色仍然只能表示会员；要给别的东西上色，先回到功能色那一节。

个人主页的六边形图是第二处照搬游戏的配色，参照游戏内近期比赛雷达：

| token | 取值 | 用途 |
|------|------|------|
| `--color-radar` | `#f59a46` | 个人数据的描边与顶点圆点 |
| `--color-radar-fill` | `#e8823a` | 个人数据的填充，30% 透明 |
| `--color-radar-plate` | `#6a6e76` | 六边形底板，20% 透明 |
| `--color-radar-grid` | `#a3a8b0` | 外框与网格线，25–30% 透明 |

- **百分位 0 落在半径 20% 处，那一圈画成淡灰实心底**，0–100 线性排到外圈：落后的玩家也画得出形状，0 落在底边上读得通
- **网格两圈均分中心底到外圈这一段**（半径 47%、73%），不对应具体数值、不标中位线：线多了图就乱
- **六个角写名称和数值**：名称 12px `muted`，数值 16px 粗体 `heading`；不另列数值、不显示综合评分
- **六个角的排布**：左上输出、右上参战、右发育、右下生存、左下辅助、左推进；左右两角的标签贴着图边，只放短词，俄文长词落在上下
- **六个角由接口的九项合成**，比例见 `app/lib/player-stats-radar.ts`，理由见 [phase-2-radar.md](../design/bigquery/phase-2-radar.md)
- 橙色与警告色、网站主色同色系，这里只在图形里出现，不上文字、按钮与图标

百科的抽选档位是第三处，照搬游戏抽选界面的五档色（`hud_lottery/colors.ts`）：

| 页面显示 | 抽选池档位 | 描边 `--color-tier-N` | 文字 `--color-tier-N-text` |
|------|------|------|------|
| T1 | 5 | `#ff4500` | `#ff7a45` |
| T2 | 4 | `#ffd700` | `#ffd84d` |
| T3 | 3 | `#a029af` | `#d07ddb` |
| T4 | 2 | `#1e90ff` | `#5aaeff` |
| T5 | 1 | `#d3d3d3` | `#d3d3d3` |

- **页面显示的编号与抽选池档位相反**：玩家习惯 T1 最强、T5 最弱，抽选池却是数字越大越稀有。数据、token 名 `N` 都按抽选池档位，只在显示时换算，和 game 仓库保持同一方向
- **描边用原色，文字另提亮一档**：紫、橙、蓝原色压在深底上读不清，档位标签与提示框副标题里的档位用文字色，标签底是原色 10%–20% 透明
- 物品池有 7、6 两档，玩家在游戏里只看得出五种颜色，网站把它们并进 5 档，显示为 T1
- **商店物品的价格档沿用这五色**：越贵越往上，最贵一档橙、最便宜一档灰，与抽奖页「越往上越好」同方向；标签写价格区间、前面带游戏金币图标。消耗道具按各自价格上色，觉醒石例外用最高一档；掉落材料没有价格，按游戏里的稀有程度上色，圣光与暗影组件、龙珠金，符文与神龙红
- 只用在百科的图标描边、档位标签，以及百科与近期战绩的提示框副标题上；T2 的金不表示会员，T3 的紫不表示勇士，理由同等级圈

## 7. 游戏图标

`public/icons/` 下那几张是从游戏包里取出来的手绘图标，与结算界面用的是同一批文件；没有手绘素材的概念用 `lucide` 线条图标补齐。两套视觉语言可以出现在同一张卡里，**但同一个概念不管出现在哪个画面，图标都要一样**——新增图标前先搜一遍现有代码里这个概念有没有已经在用的图标，有就复用，没有再挑新的。

| 概念 | 图标 |
|---|---|
| 勇士积分 | `public/icons/battle-point.png`，游戏内 `battlepass/pts_earned` |
| 金钱 | `public/icons/gold.png`，来自 Dota 公开 CDN |
| 英雄伤害 / 承受伤害 | `public/icons/hero-damage.png` / `damage-taken.png` |
| 治疗 | `public/icons/healing.png` |
| 力 / 敏 / 智 / 全属性 | `public/icons/strength.png` / `agility.png` / `intellect.png` / `universal.png` |
| 击杀 / 助攻 / 补刀 / 推塔 / 眩晕时长 / 肉山击杀 | lucide `swords` / `handshake` / `axe` / `tower-control` / `zap` / `skull`，取值见 `daily-task/TaskIcon.tsx` 的 `METRIC_ICON` |

- **图标上表头，不上每一行**：同一个符号在十行里重复是噪音，表头出现一次加上列对齐已经说明归属。没有表头的窄屏例外——那一列数字只能靠图标说明自己是什么
- **图标要带 `alt`**，值就是它顶替掉的那个列名；纯装饰（旁边已有文字）时 `alt` 留空
- 新增图标先裁掉四周全透明的边再入库，不缩放不改像素；从 CDN 取的图另外缩到 48px 以内

## 8. 网站标志

网站标志就是启动器的图标 `public/images/launcher.webp`：透明底、黑描边的角色形象。浏览器标签页的 favicon、页头左上角站名前、游戏内按钮栏的网站入口都用这一张，玩家从游戏点进网站、再下载启动器，看到的是同一个标志。

- **只用原图，不另外导出小尺寸**：标签页、页头、游戏按钮各自按显示尺寸缩小，原图 144px 在高清屏缩到 32px 仍然清晰；整张图缩到 16px 还认得出，所以不裁成只有头部的版本
- **页头里显示 32px，站名文字保留**：图标是装饰，`alt` 留空，链接名由站名提供；32px 不超过账号位撑起的 36px 行高
