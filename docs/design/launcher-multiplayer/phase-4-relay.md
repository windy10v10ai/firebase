# 启动器联机 阶段 4：中转服务器

> 状态：已完成，随启动器 0.5.0 发布；中转程序在 server 仓库。长期说明见 [启动器联机](../../../launcher/README.md#联机)，通行证约定见 [docs/api/README.md](../../api/README.md) 的「启动器联机」。

对称型网络打洞必败，公测首日约三分之一的加入者是这种网络，只能看到「连接失败」。这一阶段加中转服务器，打不通的玩家改走中转。

## 决定

- **中转是第三条路，和局域网、打洞同时试**：先打洞失败再试中转要白等 15 秒；中转先通也稍等一下，没有更好的路才用它
- **每次加入在中转上分一个单独的端口，认领一次才转发**：房主的隧道代码不用改；对称型网络换目标端口就换对外地址，必须在那个端口上认准对方
- **API 用私钥签通行证，中转只用公钥验**：中转不连 API、不连数据库，部署不用传秘密
- **中转地址由 API 下发**：换机器、加节点只改 API，不配就是关掉中转
- **先只放国内一台**：海外家用网络多数能打洞，打不通时绕到国内总比连不上强
- **中转程序自己写，不用 TURN**：只需要配对与转发，老版本 C# 接 TURN 客户端比实现一个小协议麻烦
- **先用按量计费跑几天，按实测流量再买年付**
- **费用靠中转自身的上限封顶**：开房、加入都是公开接口，通行证防不住滥用

## 不做

- API 侧按 IP 或次数限制发证：拿不到可信 IP，Steam ID 又是自报的
- 加密转发内容：游戏数据本来就是明文 UDP
