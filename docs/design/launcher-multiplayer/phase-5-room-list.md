# 启动器联机 阶段 5：房间列表显示进行中的游戏

> 状态：已实现，随启动器 0.5.2 发布。长期说明见 [启动器联机](../../../launcher/README.md#联机) 与 [启动器房间 API](../../api/README.md)。

列表上方只有一行「正在进行：N 局 · M 人」：等着的人不知道别人打了多久、值不值得等；开了房间的主机看不到列表，不知道别处有没有人在等、会不会有人进来。

## 决定

- **进行中的游戏一局一行，显示所有真人玩家的头像、地图、人数与已进行的分钟数**：一眼看出几个人在打、大概多久打完；不预估剩余时间，局长波动太大。
- **好友房的游戏也一局一行，头像换成灰色人形，地图一栏写「好友游戏」**：显得组队的人多，又不透露谁在玩；与公开游戏同一种行样式，不调暗。
- **等待加入的房间也显示房里所有人的头像**：与进行中的行一致。
- **列表顺序：自己的房间 → 等待加入 → 进行中**：能加入的优先，行多时滚动看进行中。去掉列表上方的局数统计，各段的行已经说明了。
- **开着房间时可以在「联机主机」与「加入联机」之间切换**：主机等人时也能看列表；「单人游戏」仍锁住，「联机主机」标签上加绿点提示房间还开着。
- **开着房间时不能加入别人**：加入按钮变灰、不显示房间码输入框，也不测各房间的延迟，延迟一栏显示「—」。
- **主机自己的控件只留在「联机主机」页**：房间码、关闭服务器、结算保存提示不跟到「加入联机」页，不同页面做不同的事。
- **「加入联机」标签上显示等待中的公开房间数**：让人一看就知道有房间可进，自己的公开房间也算；用蓝色小数字而不是主色，只是告知，不像未读消息那样催人点；为 0 或已在这一页时不显示。
- **自己的房间固定在最上面，标「你的房间」**：主机能确认自己的房间别人看得到、现在是什么样子；好友房也照样显示在这里。
- **列表加高到约 4 行半，横幅从 120 缩到 80、房间码说明并进输入框的提示文字**：窗口总高度与原来持平，1080p、150% 缩放的笔记本仍放得下。

## 不做

- 不做观战：开局后连进专用服的人会被怎样处理还没验证，记在路线图（#1367）的「以后」。
- 不提供「关掉我的房间并加入这个」：先看主机会不会真的这样用。
