# 启动器联机 阶段 3：开房与结束流程

> 状态：已实现，实机联机测试通过；启动器随 0.5.0（与中转服务器一起）发布，游戏内房间状态条随 game 仓库发布。长期说明见 [启动器联机](../../../launcher/README.md#联机)。

开房后 Dota 2 马上打开，主机不知道要在游戏里等人、再点「锁定并开始」；游戏打完关掉 Dota 2，主机一关服务器就断掉所有人，加入的人留在房间里或收到「断开连接」的报错，像是出了故障。

## 决定

- **主机仍然先进游戏**：先连进服务器的人成为房主，改成等人齐再启动会多等一次 Dota 2 加载，也可能让别人抢到房主。
- **开房前用绿色提示条说明接下来会发生什么**：放在难度按钮下面，玩家点开局之前就能看到；开房后 Dota 2 是全屏的，启动器上的提示几乎看不到，也不切回启动器窗口抢焦点。
- **公开房间的房间码改成灰色小字**：公开房间在列表里就能找到，醒目的房间码会让人以为必须分享；好友房保持原样。
- **服务器只由主机手动关闭**：主机关掉 Dota 2 不再关服务器，可以「重新进入游戏」；以前主机误关会让所有人掉线。
- **结算保存完、所有人都退出 Dota 2 后自动关闭服务器**：还有人在游戏里就不关；结算请求在游戏结束时才发出，立刻关服务器可能打断它。
- **保存结果期间点「关闭服务器」要确认**：给主机留退路，但说明积分可能不记录。
- **游戏结束由主机转告加入的人**：只有主机能读专用服日志；加入的人关掉 Dota 2 后自动退出房间，不再显示「重新进入游戏」或报错。
- **启动器任何时候都不关闭 Dota 2**：结束画面要留给玩家自己看完。
- **结算完成看游戏已有的结算回调日志**：不用改游戏；离线局，或回应到达前所有玩家都已退出时没有这一行，游戏结束 15 秒后视为完成。
- **游戏选队界面另加一条房间状态条，分三种状态**：只有主机时灰色「等待其他玩家加入」，有人连接时橙色列出名字，加入的人都进来后绿色「所有玩家都已进入」，右侧显示「已进入 / 上限」；公开房间不知道会来多少人，所以只说当前情况、不替主机判断该不该开始。和数据加载状态是两件独立的事，合成一条会互相盖掉。
- **名单由主机启动器在本机提供，游戏直接读**：专用服就在主机电脑上，不经过 API；读不到（从游廊开局、旧版启动器）就不显示这条。

## 不做

- 不在同一个房间直接再开一局：要重启服务器、所有人重新连接，重新开房只多点一下。
