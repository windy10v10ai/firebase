# 每日任务刷新

> 状态：已完成。规则见 [docs/api/README.md](../../api/README.md) 的「每日任务」。

Phase1 上线后，单人玩家抽到助攻、治疗这类要靠队友的任务时没有任何补救办法。这次给每个玩家免费刷新，并修掉候选生成器随机性不足的问题。

## 决定

- **每轮一次，不分会员**：每轮都可能抽到不称心的任务，每天一次只解决三分之一；刷新是补偿，卖给会员等于让非会员觉得体验被故意做坏
- **整组三个候选全换、星级重新洗牌，局内实时生效**
- **刷新次数既限额又进随机种子**：候选仍然全部重算，「候选不落库」不变，文档只多一个整数
- **不排除刚才那组**：约 5% 的概率通用槽刷回同一条，排除要回算上一组，生成器不再是单向的纯函数

## 不做

- 会员额外次数、次数累积到下一轮
- 服务端限制刷新时机：与 Phase1 的信任模型一致，交给客户端
- 刷新的日志与统计：刷新行为因此没有观测数据
- 按本局真人数调整任务池：同一轮在不同人数的局里会算出不同候选
