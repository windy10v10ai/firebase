# 每日任务网站页改版

> 状态：已完成。长期决定见 [docs/web/README.md](../../web/README.md) 的「其他页面决定」。

历史里没有今天，玩家以为今天的数据没记全；1/3 进度环和一层套一层的卡片框又显得像模板生成的。这次只改网站页面，接口不动。

## 决定

- **历史第一行固定是今天**：今天只放在「今天」卡里时，玩家在历史里找不到它；还没做的轮次写「进行中」或「—」，不画虚线空格，免得看着像缺数据
- **三轮做成轮次条，取代进度环**：一天只有 3 个离散的轮次，连续的圆环表达不对，而且和「今天已完成」的三个格子重复说了一遍进度
- **轮次用勾、箭头、锁三个图标标状态**：空心圆配实心点像单选框，玩家会以为要在这里选；没选序号方块和分段进度条，后者的橙色像能点
- **页面里不用每日任务青**：功能色只上入口图标；今天和当前轮用更亮的灰底与白色粗体标出，只有完成的勾用成功绿
- **刷新按钮降一档**：它是次要操作，原来的尺寸和本轮标题抢视线
- **电脑两栏、更窄时单列**：电脑上左栏今天、右栏历史，三轮竖排；手机和平板上三轮横排成三格，历史每天分两行。两种宽度各取对比稿里更顺眼的一种
- **30 天汇总并进历史的标题行**：单独一张卡在电脑上落到首屏外，并进去后两种宽度结构一致
- **任务去掉里层边框**：卡片里只留一层框，层级靠分隔线和字重

## 不做

- 游戏内的每日任务界面：等网站上线后再对照着看要不要跟
- 日历格子：没打游戏和打了没完成会画成同一个空格
