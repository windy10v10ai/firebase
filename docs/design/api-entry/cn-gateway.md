# 大陆入口：开局按地区选路

> 状态：进行中。后端探测端点已就绪，大陆网关待建，客户端改动见 [game#2421](https://github.com/windy10v10ai/game/issues/2421)。上级文档见[本目录 README](README.md)。

大陆玩家偶发连不上 API，表现为加载失败或结算失败。服务端日志里到达的请求几乎全部在 400 毫秒内返回 2xx，失败发生在到达之前——两个域名都在 Cloudflare 后面，免费版在大陆没有节点，流量落到香港或美西。

官方服务器停用后全部对局都是本地主机，请求从玩家家用宽带发出，跨境那一跳比机房出口更不稳。同期结算成功的对局里大陆占七成。

## 决定

- **大陆入口用云厂商的 Serverless 网关，不自建服务器**：厂商默认域名自带备案，避开 ICP 与公安双备案；这点流量在免费额度内，也不需要运维
- **按地区选路，不按谁先响应**：大陆玩家的问题是偶发断连而非慢，单次延迟抽样测不出稳定性，碰上好时刻会把整局锁在不稳的那条路上
- **国家码取自 Cloudflare 的 `cf-ipcountry`，经自己的端点回传**：直接打 `cloudflare.com` 测的是那个域名的可达性，与我们的链路无关；打自己的端点，一次请求同时得到「到 API 服务器通不通」和「玩家在哪」
- **探测端点独立于 `/api/hello`**：`hello` 返回给人看的环境字符串，探测要返回客户端解析的结构化响应，契约不同；挂在 `game` 前缀下则不必改函数的路径白名单
- **探测要鉴权**：否则它是一个公开的回显国家码接口，会被拿去当免费 GeoIP
- **网关上的探测请求回源到东京，不在网关层直接应答**：既然不做失败换路，判定一旦判错就没有补救，它必须验证业务请求真正要走的完整链路，而不是只验证第一跳
- **判不出时走 API 服务器**：宁可让大陆玩家留在原来的路上，也不让境外玩家占用网关的负荷与延迟
- **每局判定一次，不跨局缓存**：本地主机的脚本状态每局重建，跨局缓存要动 Panorama 的存储再传回服务端，为省一次小请求不值得

## 判定

选的是本局的主地址，候选两个：**API 服务器**（`api.windy10v10ai.com`，现在一直在用的地址）与**大陆网关**（待建，转发到 API 服务器）。

开局并发打两个探测端点，各 2 秒超时：打 API 服务器的取国家码，打大陆网关的只看 HTTP 状态码。

| API 服务器返回的国家码 | 大陆网关是否通 | 主地址 | 为什么 |
|---|---|---|---|
| 非 CN | 不看 | API 服务器 | 境外玩家几乎总能拿到国家码，这条把他们挡在网关外 |
| CN | 通 | 大陆网关 | 大陆玩家，网关可用 |
| CN | 不通 | API 服务器 | 网关此刻不可用，没有别的选择 |
| 拿不到 | 通 | 大陆网关 | 拿不到本身就说明到 API 服务器的链路此刻不通 |
| 拿不到 | 不通 | API 服务器 | 两个信号都没有时的安全默认 |

两条短路规则，避免总是吃满 2 秒：国家码回来是非 CN 就立刻定 API 服务器，网关那条明确失败也立刻定 API 服务器。只有「大陆玩家且到 API 服务器不通」会等满，而那正是最该走网关的人。

**打网关那条探测，响应 body 绝不能用来判国家。**它经网关回源，边缘看到的客户端是网关，body 里的国家码永远是网关所在地。境外玩家同样连得上网关、那条探测同样会通，拿 body 判国家会让所有人都被判成大陆，全球流量压到网关上。分工是死的：国家码只从 API 服务器那条取，网关那条只看状态码。

## 不做

- **不做失败换路，不改重试机制，不改结算**：选对路是一阶效应，退避与换路是二阶；一次只改一处，上线后失败率变化才归因得清
- **不做大陆入口加厂商专线**：月费几百，这点流量不划算
- **不做香港中转**：客户端那一跳仍然跨境，改善幅度小于大陆入口
- **不引 GeoIP 库**：为一个二选一的判断给函数包塞进几十兆、拖慢冷启动，不划算
- **不按客户端语言或时区判地区**：海外华人用简体中文会判成大陆，大陆玩家用英文界面会判成境外，且判错没有反馈
- **不做 ICP 与公安备案**

## 后续事项

- 网关不可用或被厂商限流时，判定成功走了网关的玩家没有补救。最小的堵法是结算的最后一次重试改用 API 服务器，等上线看数据再定
- 走网关的请求身上没有边缘给的来源头，按 IP 的活动统计会归到网关自己的地址下。限流不受影响，它全按 steamId。要拿真实 IP 得靠网关透传 `X-Forwarded-For`，但请求再经 Cloudflare 时那个头会被追加，最左是否仍是玩家地址需要等网关建好实测，不能先当成事实
- 结算失败目前完全静默，客户端三处状态写入被注释掉了。房主在重试跑完前退出就会丢分，与本批次无关但同样影响结算成功率
