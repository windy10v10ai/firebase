# Stripe 会员与积分付款

> 状态：已完成。会员页的长期规则见 [docs/web/README.md](../../web/README.md)「会员页」，回调地址、凭据与幂等做法见 [docs/api/README.md](../../api/README.md)「对外入口」「对外依赖」「一致性」。

海外玩家原来只能走 Ko-fi，付款时要在留言里手填游戏 ID，填错就不到账。网站加了 Stripe：登录后买会员或积分，付完自动到账。

## 决定

- **会员 1、3、12、36 个月，积分三档，都是一次性付款**：档位与支付宝一致；1 个月保持 Ko-fi 的 US$4
- **美元价按支付宝的人民币价折算，总价取 .99 结尾，折扣对比 Ko-fi 原价**：与支付宝同价，又是海外常见的标价；Ko-fi 是海外玩家原来的付款方式
- **订单记商品代码与份数，每档总价写死在商品表**：多月总价摊不成整分月价；加档位只改商品表
- **订单归属只认网站登录身份**：没有手填 ID 填错的问题，不支持替别人下单
- **用 Stripe 托管收银台，只开银行卡与钱包**：付款当场有结果，回调只处理一种成功事件；支付宝、微信在 Stripe 上申请未通过
- **回调照搬支付宝的顺序，不做主动查单补发**：失败让 Stripe 重试，它会重试数天，后台也能手动重发
- **商品名、权益、商品图与收银台外观每单由代码传**：跟着网站语言走，测试与正式账号不用各配一遍；权益用全角空格撑出换行
- **退款与拒付人工处理**：在 Stripe 后台操作，需要时手动扣回

## 不做

- 自动续费、优惠码
- 处理收银台过期：未付款的订单停在待付款，没有副作用
- 下单次数限额：建收银台不花钱，且必须登录
