# 本地主机策略 阶段 3：网页启动链接

> 状态：已完成。长期规范见 [docs/web/README.md](../../web/README.md) 的「开局方式与命名」与[根目录 CLAUDE.md](../../../CLAUDE.md) 的「用语」。

`steam://run/570//<编码后的启动参数>/` 这种链接能从网页直接拉起 Dota 并带上启动参数。玩家不必再开控制台、敲命令，`/offline` 从一篇教程变成一个入口。

## 决定

- **命名按三个维度分开**：动作（从游廊开局 / 在网站上开始游戏）、连接状态（离线 / 在线）、主机（本地主机 / 服务器主机）。将来会多一种由服务器主机开的局，它同样从网站上开始、同样是在线，动作名按「在哪开始」命名，到那时入口文案一个字都不用改
- **「离线」「在线」保留为连接状态的正式说法**，只是不当动作名：游戏内本来就有显示对局状态的地方，禁用它等于让 game 侧没词可用
- **解除「本地主机」的禁用**：禁它是因为它曾和「离线模式」抢同一个意思，三个维度分开后各说各的
- **区块标题叫「在网站上开始游戏」，不叫「一键开局」**：「一键」是营销词，也说不出玩家得到了什么
- **三个难度平级给三个链接**，不做默认加下拉：玩家一步到位，也不暗示哪个难度是推荐的
- **「必须退出 Dota 2 再执行」排在链接前面**：游戏开着时点链接毫无反应，玩家只会以为链接坏了。只给这半句上警告色，整条上底色会把注意力从下面三个按钮上抢走
- **两个系统提示复刻成 UI，不用截图**：截图换不了语言，也会随浏览器与 Steam 改版过时。整块对读屏隐藏，信息由上方的步骤说明承载
- **浏览器那个提示按 Chrome 的样子画**：各浏览器长相与文案都不同，取用户量最大的一个，其余靠步骤说明兜住
- **控制台那套收进折叠兜底**：`steam://` 可能被浏览器拦下，或 Steam 没接管这类链接，留一条后路成本很低
- **提示块不做「叉掉不再显示」**：要记住状态就得写 cookie 再加一个客户端组件，这一页保持服务端渲染更划算

## 不做

- 对比表不加「主机」一行：现在两种方式都是本地主机，这一行两列相同，等服务器主机真的有了再加
- 不检测 Dota 2 是否正在运行：网页做不到，只能靠文案提醒
- 站外的爱发电与 Ko-fi 页面不动，另行处理
