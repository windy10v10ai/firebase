# 本地主机策略 阶段 2：网站文案对齐离线模式

> 状态：已完成。长期规范见 [docs/web/README.md](../../web/README.md) 的「两种开局模式」与[根目录 CLAUDE.md](../../../CLAUDE.md) 的「用语」。

对应 issue [#1214](https://github.com/windy10v10ai/firebase/issues/1214)。Dota 2 7.41f 起，从游廊直接开局的对局发不出网络请求，网站上的文案还在按「游戏内点刷新就同步」「会员下一局自动生效」写，对付费玩家尤其误导。

## 决定

- **两种开局方式只叫「离线模式」「在线模式」**：与 game 侧同名，玩家在游戏内外看到的是同一套词；「控制台启动」降级成进入在线模式的操作说明，不当模式名
- **入口说现象，术语只在说明页解释**：玩家心里的话是「我改了怎么游戏里没变」，看到「离线模式」四个字反而对不上号。说明页标题「启动方式与数据生效时机」，菜单与页脚用短形式「数据生效时机」
- **完整规则只在 `/offline` 讲一遍**，其余页面一句提示加链接：口径散在各页各写一套，改一次要追七八处
- **`/offline` 进头部汉堡菜单，不进横排**：页面上线就要有菜单项，而 768 一档的横排已经排满，说明页也不是常用功能
- **对比表用 ✓ 与 —，不写「可用 / 不可用」**：五行里只有两处需要补充，其余靠符号一眼看完；补充文字只在桌面显示，手机加字会把模式列挤到折行
- **三条启动命令按难度并列给出**：地图名让玩家自己填等于多一步出错机会，直接列 dota / hard / custom 三条整命令，每条带复制按钮
- **加点、觉醒写明「为了保护玩家数据安全」只能在网站操作**：两种模式都不能在游戏内做，游戏内那两个按钮是跳转到网站，不写成「离线模式下改不了」
- **提示条用中性灰图标**：说明页不是某个功能，按 design-system.md「功能色」的规矩不占功能色；也不用警告色，它是长期状态而非告警
- **每日 100 会员积分的说法改成「每天签到再领」**：这笔积分原先由游戏开局接口发放，现在要签到才有；但不写「在网站签到」，用在线模式开局时同样会自动领取
- **商业披露页只补一句限定**，「支付成功后立即使用会员服务」照旧：权益确实在付款成功时开通，改的是游戏内何时读到
- **文案里不写没人接管的尖括号**：next-intl 按 ICU 解析 `<>`，未注册的标签名直接抛 `INVALID_TAG`（页面不崩，只在 console 报错）。模式名的加粗是有意用 `<name>` 配 `t.rich` 渲染的

## 不做

- 激活结果页不加跳转链接：纯文本说清生效时机就够，多一个按钮反而让人以为还要再操作一步
- 网站不显示快照截至日期：要后端先把导出时间吐出来，收益只是把「下次地图更新后生效」说得更具体
- 每日任务页的文案不动：页面还挂着「即将上线」
- 爱发电与 Ko-fi 站外页面的文案不动，另行处理

## 后续事项

- 爱发电、Ko-fi 的会员介绍页要跟着改一遍，那两处在站外、不随本仓库发布
- 在线模式下游戏内还能不能消费会员积分没有确认，能的话对比表要补一行
