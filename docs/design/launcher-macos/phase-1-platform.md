## 当前 PR

接替 [#1572](https://github.com/windy10v10ai/firebase/pull/1572)，基于原作者的移植完成可维护的平台接入，功能与 Windows 保持一致。

- 直接使用已有共用核心、JSON 兼容层、版本定义与 API 地址；补齐 Mac 平台接口。
- 客户端经过 Steam 启动，已开着时复用；修复平台接入发现的账号、地图与进程清理问题。
- 定位并处理启动时 macOS“修改 App 被阻止”的问题，不以要求玩家放开宽泛权限替代定位。
- 在现有 CI 中保留构建和离线测试，不增加独立 workflow、打包上传或发布步骤。
- Windows 的共用代码变化只保留跨平台复用必要部分，并明确回归范围。
- 不增加移植版本独有的产品功能；新增代码与测试必须对应 Windows 功能或已确认的平台问题。
