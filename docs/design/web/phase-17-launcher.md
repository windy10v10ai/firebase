# 批次 17：启动器

> 状态：设计中。

从游廊开局跑的是本地主机：服务器逻辑和游戏画面挤在同一个进程里，10v10 后期明显卡顿。启动器 `Windy10v10AI.exe` 在玩家电脑上单独开一个服务器再连进去，两者分到不同核心；本机实测后期平均帧率从 7 升到约 65。启动器源码与设计在 server 仓库（`launcher/`、`docs/design/local-launcher.md`），这一批只管官网怎么发布它、怎么向玩家介绍，以及游戏加载界面的入口。

## 决定

- **叫「启动器」，不强调开局**：英文 Launcher，俄文 Лаунчер。对比表两列简化成名词「游廊 / 启动器」；需要动词时加「用」「下载」。没选「专用启动器」：「专用」会让玩家联想到专用服务器，多一层理解
- **启动器完全替代从网站启动游戏**：网站启动链接跑的也是本地主机，启动器同样只能单人、同样直连服务器，还解决了后期卡顿。推翻「网站启动降级不删除」：那条是为将来的服务器主机留入口，`/launch` 页现在就是那个入口，玩家看到的位置不变
- **exe 放官网 `public/downloads/`，随官网部署**：玩家本来就要上官网加点、觉醒，官网在哪能打开，下载就在哪能用。没选 GitHub Release（国内常打不开）、Firebase Storage（googleapis 国内不通）、腾讯云 COS（要多维护一套存储，国内 CDN 还涉及备案，150 KB 的文件不值得）
- **文件名带版本号、永久缓存**：请求经 Cloudflare → App Hosting CDN → Next，`public/` 默认只缓存 4 小时，而 App Hosting 的弱 ETag 只看文件大小，新版恰好同样大时各层缓存会一直发旧版。改用 `Windy10v10AI-<version>.exe` 加 `immutable`，与 `/dota/` 立绘同一套做法
- **玩家保存下来的文件名固定为 `Windy10v10AI.exe`**：换版本不在玩家电脑上留一串带版本号的文件，快捷方式也不用重建。下载链接加 `download` 属性，同时给该路径的响应加 `Content-Disposition: attachment; filename="Windy10v10AI.exe"`，直接打开下载地址、或浏览器不认 `download` 属性时也存成同一个名字。下载按钮下方写出文件名，和首次运行弹窗里「应用：Windy10v10AI.exe」对得上
- **对比表加一行「后期流畅」**：游廊 △，启动器 ✓。只用符号，不写帧数：7 → 65 是一台机器的实测，写上去玩家会拿自己的电脑对照
- **首次运行说明用简略示意图，重点标「更多信息」**：没有代码签名，Windows 会拦下来源不明的程序。弹窗颜色和样式因电脑而异，所以不仿真，只画中性色的简图分两步：先点「更多信息」，再点「仍要运行」。「更多信息」是一行小字链接，多数人注意不到，示意图里用高亮框和序号把它标出来。第二步的「仍要运行」在「不运行」左边，示意图按 Windows 原样排，玩家是按位置找按钮的，画反了会点错。说明文字只留一句「第一次打开时 Windows 会拦一下，按下图允许运行即可」。浏览器下载栏可能也提示「不常下载」，页面上先不写，看玩家反馈再加
- **游戏加载界面的提示框始终显示，换成新样式**：原来只在读不到玩家数据时显示「游廊开局连不上服务器？」。卡顿与连没连上无关，所有玩家都该知道有这个选择；火焰橙边框加「新」角标，和启动器配色一致，与旧提示区分开，让玩家知道这是新东西。按钮跳 `/launch` 的下载区

## `/launch` 页结构

1. 对比表：标题改为「两种启动方式」，两列游廊 / 启动器，现有几行加上「后期流畅」。表头徽章同为绿色：游廊「联机」，启动器「单人」，只说适合的场景，不分主次。格子里只放符号，符号已说清的不再加注（✗ 旁不写「只能单人」，「后期流畅」一行不加注）。表下的离线说明保留
2. 下载启动器：图标与一句介绍、下载按钮（下方一行「Windy10v10AI.exe · 版本 · 大小」）、一句首次运行说明加两步示意图。不列使用条件：只能单人已在对比表里，装了 Dota、订阅了地图是玩这张图的前提
3. 加点和觉醒只能在网站上操作：不变

删掉：网站启动链接与三个难度卡片、浏览器与 Steam 两个系统弹窗的示意、控制台命令一节。

## 连带改动

- 首页启动卡片的说法换成启动器；页脚只有一个「启动游戏」链接，不用改
- `CLAUDE.md` 与 `docs/web/README.md` 的「用语」「开局方式与命名」改成游廊 / 启动器；主机维度表里启动器一行是服务器主机
- game 仓库：加载界面提示框的布局与样式、`console_launch_*` 与 FAQ 中英俄文案

## 发布顺序

1. server 仓库编译 exe，复制到本仓库 `web/public/downloads/`，改下载链接里的版本号，官网部署
2. game 仓库改加载界面，随下一次地图更新发布。游戏更新比官网慢，先上官网，玩家点提示框按钮时看到的已是新页面

## 不做

- **代码签名**：证书一年几百美元起，等启动器用户量证明值得再买
- **仿真 SmartScreen 弹窗**：各电脑样式不同，仿得越像越容易对不上
- **启动器内的版本更新提示**：需要官网上的版本文件，放到下一批，和本批的带版本号文件名一起用
