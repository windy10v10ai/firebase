# 批次 17：启动器

> 状态：官网部分已完成，游戏加载界面待 game 仓库。长期规范见 [docs/web/README.md](../../web/README.md) 的「开局方式与命名」。

从游廊开局时，服务器逻辑和游戏画面挤在同一个进程里，10v10 后期明显卡顿。启动器 `Windy10v10AI.exe` 在玩家电脑上单独开一个服务器再连进去，本机实测后期平均帧率从 7 升到约 65。启动器本身在 server 仓库（`launcher/`），这一批管官网怎么发布、怎么介绍它。

## 决定

- **叫「启动器」**：没选「专用启动器」，「专用」会让玩家联想到专用服务器
- **启动器完全替代从网站启动游戏**：网站启动链接同样只能单人、同样直连服务器，却解决不了后期卡顿；`/launch` 仍是入口，玩家看到的位置不变
- **exe 放官网 `public/downloads/`**：玩家本来就要上官网加点、觉醒；没选 GitHub Release、Firebase Storage，国内常打不开
- **服务器上带版本号、玩家存下来固定叫 `Windy10v10AI.exe`**：带版本号才能永久缓存不发旧版；保存名固定，换版本不留一串旧文件
- **对比表加一行「后期流畅」，只用符号不写帧数**：7 → 65 是一台机器的实测，写上去玩家会拿自己的电脑对照
- **两行「遇到什么、怎么做」加两张中性色简图**：没有代码签名，下载和运行各被拦一次；弹窗外观因电脑而异，不仿真
- **游戏加载界面的提示框始终显示**：卡顿与连没连上服务器无关，所有玩家都该知道有这个选择；火焰橙边框加「新」角标，与旧提示区分开

## 不做

- **代码签名**：证书一年几百美元起，等启动器用户量证明值得再买
- **页面上列使用条件**：只能单人已在对比表里，装了 Dota、订阅了地图是玩这张图的前提

- 启动器读官网版本文件，发现新版时提示去官网下载
