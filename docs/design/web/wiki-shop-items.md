# 百科收录商店物品，战绩物品可点开看说明

> 状态：设计中。功能与数据范围已定，界面设计下一步再做。实现完成后，长期有效的决定并进 [docs/web/README.md](../../web/README.md) 与 [ability-tooltip.md](../../web/ability-tooltip.md)，本文整篇删除。

百科的物品页只收抽选池里的物品，商店里的自定义合成物品查不到；个人战绩里的出装只有图标和名字，点了没有反应。

## 物品页分两类

| 分类 | 收哪些物品 | 怎么分区 |
|---|---|---|
| 商店（默认） | 商店里的自定义物品，加上商店里没有位置、靠配方合成的自定义物品 | 按价格分五档，另加「掉落合成」分区 |
| 抽奖 | 抽选池里的物品 | 抽奖档位，同现在 |

- **默认显示商店**：商店是每局都会逛的地方，抽奖池是固定的一小批
- **两类各看各的，不做「全部」视图**：两边的分档方向相反，抽奖 T1 最稀有，价格 T1 最便宜，放在一个视图里没法排
- **一件物品既能抽到又能买到，两边都列**，各显示各自的档位
- **搜索两类都查**：结果在另一类里时提示玩家切过去，免得以为没有这件物品
- **格子提示里那一行照技能页的写法**：分类加档位，商店物品写价格，如「商店 · 12,500 金」

## 商店收录范围

- **只收自定义物品**：百科页是给玩家查本地图特有的东西的，原版 Dota 物品（包括 game 改了数值的）不进百科页
- **商店里没有位置的合成物品也收**：配方可以直接买，凑齐材料就能合出来，玩家照样会拿到
- **由同步脚本按规则推算**，不手工维护名单：新加的合成物品自动收进来
- **单独排除的物品写成排除名单**，目前只有秘奥闪光

## 分档：按价格，不按合成关系

- **按价格分档**：每件物品只有一个价格，档位唯一；合成关系是一张网，有多条合成路线、有升级版本，一件物品会同时落在两层
- **档位边界与 bot 出装的分档一致**：2000、5000、10000、30000 金四条线
- **价格从 game 的物品配置算**：配方价加材料价逐层加总，同游戏里看到的价格；不读 bot 的分档配置，那份是手写的，有些物品没写
- **分区标题写价格区间，不写 T 编号**：抽奖页已经用 T1 表示最稀有，商店再用 T1 表示最便宜，玩家会弄混

## 掉落合成分区

- **收打怪掉落的材料，以及要用它们合成、又没有价格的物品**：龙珠、八种符文、圣光与暗影组件、神龙与神龙赐福
- **商店里有位置的物品照常按价格分档**，哪怕合成要用到掉落材料：圣光臂章、暗影臂章都在 10000–30000 金这一档

## 战绩里点开物品与技能（这一步）

- **用百科同一套说明组件**：从百科页抽出「加载说明 + 悬浮提示 + 详情弹窗」，百科与战绩共用，样式只有一份
- **技能格子一起接上**：说明数据百科已经有了，多接一处成本很小
- **这一步只有百科收录的物品能点**，原版物品的格子保持现状，下一步再补
- **说明数据第一次点开时才加载**：战绩页不像百科页那样一打开就加载，不让个人主页变重

## 下一步：原版物品的说明

- **只给战绩用，不进百科页**：战绩里的出装大半是原版物品，点不开就缺了一大块；百科页仍只放自定义物品
- **说明数据与百科分开成包**：百科页不用为用不到的原版物品多加载数据

## 不做

- 不按合成关系分层：理由见上文「分档」
