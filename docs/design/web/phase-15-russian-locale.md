# 批次 15：俄语支持

> 状态：已完成。语言探测、回退与切换控件的规范见 [docs/web/README.md](../../web/README.md) 第 4 节「多语言」。

网站只有中英两种语言，切换控件是一个「文 / A」按钮，已经卡在 44px 的宽度上限上，塞不下第三个标记。

## 决定

- **控件改成图标加当前标记、点开是母语名列表**：宽度恒定 38–43px，再加语言也不变；三段横排「文 / A / Я」估算 57–66px，越过 375 的上限
- **不用循环按钮**：三种语言起点一下切下一种就看不到有哪些选项，中文到俄语中间还要闪过一次英文界面
- **俄语标记用「Я」**：字形最像西里尔，「Р」会被读成拉丁 P，「RU」与英文的「A」撞同一套字母
- **俄文译法对齐 game 仓库的 `addon_russian.txt`**：Профиль、Атрибуты、Пробуждение、Задания 都取自游戏内同名面板，「启动游戏」跟着游戏的「Запуск игры」取 Запуск
- **没译到的 key 深合并回落英文**：一种语言可以只译一部分就上线，不必等整份译完，混排的英文至少能读
- **浏览器语言探测按 `Accept-Language` 自身的优先级取第一个支持的**：俄语用户首次进站直接看到俄语，只判「是不是中文」的两路探测给不出第三种语言
- **768 的横排导航只放四项**（启动游戏、个人主页、任务、会员）：俄语六项实测 916px，放不进 768；英文六项在这一档本来也超出 55px，一并修掉

## 不做

- 不加 URL 前缀（`/ru/...`）：语言存 cookie，改路由要动所有站内链接与 API 转发规则，换来的只是可分享带语言的链接
- 头部以外的页面本轮不译：先把框架与入口做对，其余译文量大且要人工校对
