# 批次 15：俄语支持

> 状态：已完成。语言探测、回退与切换控件的规范见 [docs/web/README.md](../../web/README.md) 第 4 节「多语言」。

网站只有中英两种语言，切换控件是一个「文 / A」按钮，塞不下第三个标记。

## 决定

- **切换控件改成图标加当前标记、点开是母语名列表**：再加语言宽度也不变；没选循环按钮，三种语言起点一下就看不到有哪些选项
- **俄文译法对齐 game 仓库的 `addon_russian.txt`**：玩家在游戏内外看到同一个词
- **没译到的条目回落英文**：可以只译一部分就上线，混排的英文至少能读
- **首次进站按浏览器语言自动选**：俄语用户直接看到俄语
- **横排导航放不下时只留四项**（启动游戏、个人主页、任务、会员）：俄语在所有宽度都这样，超出的正是游戏原词，不缩短

## 不做

- 不加 URL 前缀（`/ru/...`）：语言存 cookie，改路由要动所有站内链接与 API 转发，换来的只是可分享带语言的链接
- 英雄名与技能说明本轮不译：它们由同步脚本从 game 仓库生成，要改的是脚本

## 后续事项

- 同步脚本从 game 仓库导出英雄名与技能说明的俄文（觉醒页、每日任务的英雄名）
