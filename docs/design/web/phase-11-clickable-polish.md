## 1. 属性页：等级框改成带箭头的入口

属性点卡里「勇士等级」「会员等级」两个框是跳个人主页的链接，但外观和旁边不能点的「可用 / 总数」框一样，只靠底部说明句末尾的「点等级看明细。」提示能点。

**改成由框本身表达「能点」，说明句删掉。**

- 删文案：中文「点等级看明细。」，英文 "Tap a level for details."
- 两个框的数值右侧加 16px `ChevronRight`，`--color-muted`。与首页「主要页面」卡片同一个图标、同一尺寸
- 悬停：描边换成所属货币的边色（勇士 `--color-season-border`、会员 `--color-member-border`），底色 `--color-control` → `--color-control-hover`，箭头提亮到 `--color-heading` 并右移 2px
- 「可用 / 总数」不能点，不加箭头、不加悬停

**会员框悬停用金边，不用 `card-hover` 的紫边。** 金色数值的框悬停变紫，与「勇士一律紫、会员一律金」冲突（phase-7-visual-style.md 第 2 节）。

**悬停比首页卡片多动一层底色和箭头。** 这两个框本身是 `--color-control` 底、1px 灰边，放在卡片里只变边色，深色底上几乎看不出变化。首页卡片面积大、底色是 `--color-panel`，只变边色已经够，不跟着改。

## 2. 可点击元素：光标与悬停

### 按钮为什么没有手型

**疏忽，不是特意的。** Tailwind 4 的 preflight 删掉了 `button { cursor: pointer }`（Tailwind 3 有），`<a>` 的手型是浏览器默认给的。于是站内用 `<a>` / `Link` 做的控件都是手型，用 `<button>` 做的全是箭头。汉堡按钮和语言切换「文 / A」都是 `<button>`。此前的设计文档没有讨论过光标。

现在是箭头的控件：

| 位置 | 控件 |
|---|---|
| 头部 | 汉堡按钮、语言切换、账号控件里的退出图标（电脑宽度） |
| 头部菜单 | 「退出登录」一行 |
| 属性页 | 「重置属性」、加减器 − / +、「升级」/「升至 N 级」 |
| 重置弹窗 | 两个重置按钮、「取消」 |
| 登录回调、激活结果 | 公共 `Button` 组件 |

### 做法

`web/app/globals.css` 的 base 层加一条全局规则，不在调用点逐个写 `cursor-pointer`：

```css
@layer base {
  button:not(:disabled),
  [role='button']:not([aria-disabled='true']) {
    cursor: pointer;
  }
  button:disabled {
    cursor: not-allowed;
  }
}
```

写在全局，新写的按钮不需要记得加；这也是 Tailwind 4 升级指南给的做法。`.btn-*` 与 `Button` 里的 `cursor-not-allowed` 随之多余，一并删掉。

属性卡进度条格子与生效徽章保留 `cursor-help`：悬停是看说明，不是点击。

### 同类问题

| 位置 | 问题 | 改法 |
|---|---|---|
| 个人主页「英雄觉醒」入口卡 | 页面没上线、不能点，却带紫色右箭头 | 照首页「即将上线」卡：虚线描边、图标与标题转 `--color-muted`、去掉箭头、加「即将上线」标签 |
| 个人主页「可用属性点」一行 | 整行是链接，`link-hover` 写在外层，里面文字各自指定了颜色，悬停没有任何可见变化；也没有箭头 | 补箭头，悬停时箭头提亮 |
| 属性页两个等级框 | 能点但没有箭头；会员框悬停变紫 | 见第 1 节 |
| 入口卡悬停强度 | 首页卡片是 `card-hover`（40% 紫），个人主页入口卡是 `hover:border-season`（实色紫） | 统一用 `card-hover` |
| 禁用按钮光标 | `.btn-*` 禁用是禁止符号，加减器与弹窗「取消」禁用仍是箭头 | 由上面的全局规则统一 |

### 规约

实现时写进 `web/CLAUDE.md` 新增一节「可点击元素」，理由写进 `docs/web/README.md` 第 4 节：

- 能点的一律手型，靠全局规则，不在调用点写 `cursor-pointer`；可点击的控件用 `<button>` 或 `<a>`，不用 `<div onClick>`
- 整张卡或整行是链接时，右侧放 `ChevronRight`，悬停要有可见变化；不能点的不放箭头
- 悬停描边随货币：勇士紫、会员金；不属于任何货币的入口用 `card-hover`

## 3. 个人主页：会员状态并入身份卡，身份卡与等级同一行

电脑宽度下，左栏 320px 放身份卡与会员状态卡，右栏依次是等级卡、两张入口卡、战绩卡。左栏内容少，下半截空着；会员状态单独一张卡，只有两行字加一个按钮。

### 身份卡

照首页玩家卡的写法：56px 头像，「ID xxx」，下一行会员状态（有效时金字）与有效期；非会员这一行留空，与首页一致。卡片底部一行：左侧点赞举报净值，右侧文字链接「会员订阅 ›」。

金色「前往订阅」按钮换成文字链接。会员状态在这里只做陈述；订阅入口仍在，但不需要一个与页面主操作同等分量的金色按钮。

### 布局：选方案 B

**方案 A（未采用）**：第一行三张等宽卡——身份 | 勇士等级 | 会员等级，等级卡拆成两张；「可用属性点」一行删掉。第二行两张入口卡并排，第三行战绩卡通栏。

- 一张卡一件事；与批次 10 定的「电脑 3 列」一致；三张卡内容高度接近，行内不留空
- 删掉的一行不丢信息：属性入口卡的标签就是「可用属性点 N」

**方案 B（采用）**：第一行身份卡占 1/3、原等级卡占 2/3，等级卡不拆，「可用属性点」一行保留并补箭头。以下同 A。

- 改动小，等级卡保持一张，勇士与会员两套数据仍并排对照
- 代价：一行里一窄一宽两种卡；可用属性点在等级卡与入口卡上各出现一次

两套方案共同的连带变化：身份卡不再独占左栏，入口卡与战绩卡变成通栏，入口卡并排后单卡约 612px。

窄屏：手机单列，顺序为身份 → 勇士 → 会员 → 属性入口 → 觉醒入口 → 战绩；平板身份卡与等级卡各占一行通栏。
