# 批次 16：排行榜

> 状态：已完成。页面、入口与缓存规则见 [docs/web/README.md](../../web/README.md) 第 3 节「排行榜」。

游戏里的排行榜页面一直没有入口，取数接口也没人调用。这一批把排行榜搬到网站：`/leaderboard` 列出勇士积分前 500 名，底部显示自己的名次；game 仓库里那套页面与取数代码删掉。

## 决定

- **快照只存前 500 名，带昵称与头像**：原来存 1000 个 SteamId 加五条分数线，只为估出「2000+」这类档位；改成实时数人数后分数线用不上，网站也需要现成的昵称才能一次画出整张榜
- **自己的名次实时数，封顶 10000**：Firestore 的计数查询按扫过的索引条目计费，封顶后单次最多 10 次读取；排除名单不参与计数，最多差几名
- **在榜上的名次取自榜单，不取实时值**：榜单是当天快照，实时名次可能已经变了，两个数字对不上玩家会以为出错了
- **页面由浏览器取数，不做服务端缓存**：根 layout 读 cookie，全站按请求渲染，整页 ISR 做不到；Next 的数据缓存存在每个实例的本地磁盘上，App Hosting 缩到 0 就没了。改用 HTTP 缓存头，浏览器十分钟内重开不发请求
- **个人名次不做缓存**：服务端缓存省不下几次读取；浏览器侧的「先显示旧值」是 #1175 的事，不拿这一个数字先落地那套机制
- **名次按 1 / 10 / 100 分四档，放进同宽胶囊**：靠前的名次都值得标出来，不止前三；胶囊同宽让位数不同的名次对齐，分档只靠底色，不在数字旁加图标
- **「我的排名」贴底、整条可点**：翻 500 行时一直看得见；按钮文案没有合适的短说法，整条可点的点击面积最大，箭头形状与行尾的 `>` 不同，不会被当成「去我的主页」
- **入口：首页卡、菜单、个人主页入口卡，头部横排不加**：横排已满，排行榜是只看不改的页面
- **个人主页入口卡两张一行、去掉说明小字、标签移到标题下方**：四张卡竖排太长；俄语的标题与标签并排放不下
- **game 侧整条删除，不对接新接口**：从游廊开局连不上 API，对接后也只有从网站启动游戏的那一局能看到，入口还要另做

## 不做

- **行点进别人的个人主页**：现阶段只能看自己，点了只会看到 403
- **显示积分数值**：游戏里的榜单本来就不显示
- **显示快照更新时间、「实时」标记**：玩家不需要区分这两件事
