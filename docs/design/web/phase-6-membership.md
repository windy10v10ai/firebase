# 批次 6：会员页（状态与购买）

> 状态：已完成。长期决定见 [docs/web/README.md](../../web/README.md) 第 3 节「会员页」，购买区用品牌色的例外见 [design-system.md](../../web/design-system.md)「品牌色」。跟踪 issue [#1123](https://github.com/windy10v10ai/firebase/issues/1123)。

游戏内能看会员状态、用支付宝扫码买会员和会员积分，网站成为买会员的第二入口。

## 决定

- **会员与积分放同一页，上下排列**：分成两页，玩家不一定会点到第二页
- **只有支付宝要登录**：订单由我们下，离不开玩家 ID；爱发电、Ko-fi 未登录也能直接跳转付款
- **点档位就付款**：「先选档位再点付款」太麻烦
- **付款成功不显示可用积分**：玩家容易误以为比累计积分少，回到页面就能看到
- **可以给别人下单**：钱由下单的人付，等于送礼
- **网站与游戏内共用每日下单次数，价格表在网站写一份**：与 API、game 手动同步

## 不做

- **支付宝补单、回调丢失的对账**：暂不考虑
- **手机「打开支付宝」按钮**：先只做扫码
- **推荐档位标记**
