# 批次 6：会员页（状态与购买）

> 状态：已完成。长期决定见 [docs/web/README.md](../../web/README.md) 第 3 节「会员页」，购买区用品牌色的例外见 [design-system.md](../../web/design-system.md)「品牌色」，API 侧见 [docs/api/README.md](../../api/README.md)。跟踪 issue [#1123](https://github.com/windy10v10ai/firebase/issues/1123)。

游戏内能看会员状态、用支付宝扫码买会员和会员积分，网站的 `/membership` 只有权益介绍和两个订阅外链。这一批把游戏那套搬到网站，网站成为买会员的第二入口。

## 决定

- **会员与积分放同一页，上下排列**：分成两页，玩家不一定会点到第二页
- **所有购买都先登录**：支付宝下单离不开玩家 ID，爱发电登录后能把 ID 带进链接，三家做法一致
- **付款方式用三个标签切换，默认选中按语言**：中文支付宝、英文 Ko-fi、俄文爱发电，各语言玩家最常用的那家排在眼前
- **点档位就付款**：没选「先选档位再点付款」，多一步且爱发电本来就是直接跳转，两种交互不统一
- **档位卡中性底加 3px 品牌色顶条**：整块刷品牌色或渐变都显得廉价，顶条只回答「现在用哪家付」
- **划掉的原价取爱发电价**：与游戏里的折扣口径一致，折扣标签贴在现价旁边
- **说明条只给操作引导**：不在界面上解释平台限制，规约见 [web/CLAUDE.md](../../../web/CLAUDE.md)「界面文案」
- **支付成功不显示可用积分**：买积分后可用积分可能比累计少，玩家容易误以为到账少了
- **现有下单、查单接口直接挂网站鉴权，不核对 steamId 归属**：替别人下单等于送礼，钱由下单的人付；别人用你的 ID 下单最多占掉你当天的下单次数，付款成功就清零
- **网站与游戏内共用每日下单次数**：换个入口不能多下单
- **价格表在网站写一份**：与 API、game 手动同步，不开价格接口

## 不做

- **积分流水页**：后端没有流水记录，价值不够
- **支付宝补单、回调丢失的对账**：等玩家来问再做
- **手机「打开支付宝」按钮**：先只做扫码
- **推荐档位标记**：档位按月数从左到右排，由玩家自己挑
