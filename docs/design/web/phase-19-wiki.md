# 批次 19：技能与物品图鉴

> 状态：进行中。批次 A 技能页、批次 B 物品页。长期规范见 [docs/web/README.md](../../web/README.md) 第 3、4 节、[ability-tooltip.md](../../web/ability-tooltip.md)、[design-system.md](../../web/design-system.md) 第 6 节「抽选档位」。

玩家在游戏里抽到技能、开到物品时只看得到名字和图标，想提前知道池子里有什么、某个技能具体做什么，只能进游戏试。#1309 把抽选池整份搬上网站。

## 决定

- **收录范围就是抽选池**：技能收开局抽选的主动、被动两池；物品只收藏宝箱抽选池的 54 个，不做全量物品图鉴，战绩出装那份 432 个物品的清单不在这里列
- **按档位排，不按英雄或字母**：档位就是玩家在游戏里看到的稀有度，同档内保持 game 抽选池里的顺序
- **物品 T7、T6 并进 T5**：游戏里只看得出五种颜色，网站照玩家看到的来
- **全部展开，不收起**：要找某个技能靠搜索，搜索不分界面语言，中英俄名字都能搜到
- **提示框副标题写「主动 · T4」，不写英雄名**：抽选技能很多是自定义的，没有对应英雄
- **技能块、悬浮提示、详情弹窗与觉醒页共用**：觉醒页的实现抽成公共组件，wiki 的弹窗没有付费按钮，高度随内容
- **只进菜单，不上横排**：只看不改的页面，与排行榜同一口径；首页入口卡同时放开
- **说明数据单独成包按需加载**：图标墙随页面出，说明在浏览器里补上；整份说明压缩后约 120KB，跟着每次页面下发太重。带 hash 的图标目录一并改成永久缓存
- **数据源只认 game develop**：同步脚本与觉醒同步共用取数，抽选池、KV、本地化都从 game 读；原版技能要的 `docs/reference/<版本>/` 由人手工解包

## 不做

- 不公开抽中概率：概率随开局点位与藏宝箱种类变，一个数字说不清
- 不显示物品价格与合成：抽到的物品不花钱
