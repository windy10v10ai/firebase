# 批次 2g：顶部布局

> 状态：已完成。头部现在长什么样、菜单怎么排见 [docs/web/README.md](../../web/README.md) 第 3 节「菜单」，当前页标记与悬停见 [design-system.md](../../web/design-system.md)。

改之前头部有四个毛病：文案太长（「Steam 创意工坊」「通过 Steam 登录」各占一大截），桌面横排与窄屏汉堡是两套内容，登录 44px、语言 26px、退出 30px 三种尺寸，站内外链接混排且站内项今后还要加。

## 决定

- **横排文案缩到最短，菜单里用完整名称**；桌面也保留汉堡菜单，与窄屏同一套内容与顺序——横排省地方，菜单负责说清楚
- **语言在左、登录/ID 在右**，登录与 ID 统一 36px；语言保留「文 / A」与底色但降到 28px 并另隔一道分割线——靠尺寸和位置退到次要，不靠改样式
- **站内在前 → 分割线 → 站外**：创意工坊只在菜单里出现，桌面横排只留 GitHub 图标
- **菜单的站外行左侧放站点标识、右侧留外链箭头**：图标认站点，箭头示意离站
- **ID 与退出合并成一个 36px 控件**；手机与平板只显示人形图标，退出移进菜单底部。ID 文字到电脑宽度才出现——平板从 768 起就有横排导航，再加 ID 文字，英文已登录、10 位 ID 时会把汉堡挤出视口
- **个人主页在导航里另占一项**，不靠 ID 控件当唯一入口：那个控件未登录时根本不出现，手机与平板上又只是一个图标
- **命名**：`/wiki/*` 那组横排叫「技能物品」、菜单与页面标题叫「技能与物品」，英文统一 Skills & Items。不用「图鉴」——那说法像收集图册，这两页实际是查开局能抽到什么的对照表。个人主页横排不缩写，「我的」读不出是它的简称

## 宽度硬约束

窄屏已登录一行最挤，两条实测得出、后续不能踩的约束：

- **语言按钮不能回到 58px**。「文 / A」配 36px 高、8px 内边距时是 58px 宽，375 下会把这一行顶出视口；28px 高、7px 内边距的 44px 是量出来的上限
- **`md` 以下品牌一律收成「10v10AI」**。写全名在 375 放不下右侧控件：已登录时配完整 ID 溢出，未登录时英文「Sign in」同样溢出 10px

## 不做

- 视觉风格（颜色、字体、面板装饰）属于批次 7，本批只定结构与尺寸
