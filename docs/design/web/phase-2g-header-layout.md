# 批次 2g：顶部布局

> 总体规划见 [README.md](README.md)。本批只改头部这一个公共组件，不动任何页面内容。

## 一句话结论

**头部分成三段——左品牌、中站内导航、右账号与语言；桌面和窄屏共用同一套汉堡菜单；站内项在前、站外项在后并用图标区分；语言按钮降为次要控件。**

## 为什么排在 3a 之前

属性页、觉醒页的入口都在头部菜单里。菜单结构不定，那两页上线时头部要再改一次，`Header.tsx` 会被连续动三回。

视觉风格（批次 7）要「打磨基础组件」，头部结构先定好，那批只调 token 取值，不必为结构返工。

## 现状的四个问题

当前 [Header.tsx](../../../web/app/components/Header.tsx) 在桌面把链接横排在右侧，紧挨登录按钮；窄屏收进汉堡。

| # | 问题 | 说明 |
|---|---|---|
| 1 | 文字过长 | 「Steam 创意工坊」「通过 Steam 登录」各占一大截，三个导航项加登录按钮已顶满右半边，再加属性、觉醒、技能物品放不下 |
| 2 | 两端不一致 | 桌面横排、窄屏汉堡，内容与顺序是两套 |
| 3 | 控件大小不一 | 登录按钮 44px，语言按钮 26px，相差 18px；已登录时 ID 是纯文字、退出是 30px 方块，又是第三种尺寸 |
| 4 | 站内外混排 | 创意工坊、GitHub 排在会员订阅前面，没有区分；站内项今后还要加属性、觉醒、技能物品 |

## 结构

### 桌面

```
[品牌]        属性 觉醒 会员 技能物品 │ ⓖ │ [文/A] │ [Dota2 ID 12345678 ⏻] [☰]
```

左品牌回首页；中间横排**只放站内项**，文案缩到最短；分割线后是站外，GitHub 只留图标；右侧语言、账号、汉堡。

### 窄屏

```
[品牌]                            [文/A] [🎮 登录] [☰]
```

中间横排整体收起，其余与桌面同构。已登录时品牌收成「10v10AI」——写全名配上完整 ID 在 375 会横向溢出。

### 菜单（两端同一套）

```
属性加点
英雄觉醒
会员订阅
技能与物品
──────────────
🎮 Steam 创意工坊   ↗
 GitHub            ↗
──────────────
退出登录（仅窄屏）  ⏻
```

**桌面也保留汉堡**，内容与窄屏完全一致：横排用缩写省地方，菜单用全称负责说清楚。

## 定下的六条

1. **横排文案缩到最短**，菜单里用完整名称。
2. **桌面也保留汉堡菜单**，与窄屏同一套内容与顺序。
3. **语言在左、登录/ID 在右**，登录与 ID 统一 36px 高。
4. **语言按钮保留「文 / A」与底色**，但降到 28px 并另隔一道分割线——靠尺寸和位置退到次要，不靠改样式。
5. **站内在前 → 分割线 → 站外**；创意工坊只在菜单里出现，桌面横排只留 GitHub 图标。
6. **菜单的站外行左侧放站点标识、右侧留外链箭头**：图标认站点，箭头示意离站。站内项左侧留等宽缩进保持对齐。

## 账号区

已登录时 ID 与退出**合并成一个 36px 控件**，不再是「文字加一个小方块」两种高度。点 ID 进个人主页 `/profile/<steamId>`；窄屏退出移进菜单底部，头部只留进入个人主页这一个动作。

「Dota2 ID 12345678」是**过渡写法**。批次 9（Steam 昵称头像）上线后，这个位置换成头像加昵称。

## 命名

面向玩家的文案按 [README.md](README.md) 的用语表。本批新定一处：`/wiki/abilities`、`/wiki/items` 这组页面，横排叫**技能物品**，菜单与页面标题叫**技能与物品**。

「图鉴」不用——那个说法像收集图册，这两页实际是查开局能抽到什么的对照表。

## 宽度约束

窄屏已登录一行最挤，实测数据（Playwright 量 `getBoundingClientRect`）：

| 宽度 | 品牌 | 右侧控件 | 间隙 | 横向溢出 |
|---|---|---|---|---|
| 375 | 66 | 224 | 13 | 无 |
| 390 | 66 | 224 | 28 | 无 |
| 1280 | 138 | 635 | 379 | 无 |

两条由此而来的硬约束：

- **语言按钮不能回到 58px**。「文 / A」配 36px 高、8px 内边距时是 58px 宽，375 下会把这一行顶出视口。28px 高、7px 内边距的 44px 是量出来的上限。
- **窄屏已登录时品牌必须收短**。「Windy10v10ai」配「Dota2 ID 12345678」在 375 溢出 18px。

实现后按 [web/CLAUDE.md](../../../web/CLAUDE.md) 的「验证宽度」重跑 375 / 768 / 1280。768 这一档本批没量过——它是横排由汉堡切回的临界点，实现时要确认中间横排在该宽度放得下，放不下就把切换断点往上调。
