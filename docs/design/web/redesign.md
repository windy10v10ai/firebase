# 网站改版

> 状态：设计已定，按下面的路线分 PR 实现。长期规范（配色、按钮、可点击卡片）已写进 [docs/web/design-system.md](../../web/design-system.md)，本文只记这次改版的路线、各页设计与设计稿链接，全部完成后整篇删除。

网站底色是纯黑，配冷色的交互色，看起来单调、没有游戏的气氛。这次换成暖调主色，首页首屏放游戏封面图，并把全站的按钮、卡片、链接统一成一套写法。

## 决定

- **方向用「余烬暖调」**：暖橙主色配游戏封面图，比纯黑配冷色更有活力
- **首页首屏用暖色底渐变到中性，其余页面用中性炭黑**：整页偏红看久了累
- **橙色不写字**：链接用标题色加下划线，卡片的操作文字放进胶囊；橙只上按钮与标记
- **主按钮用杏色渐变配黑字，扁平不做厚边**：亮橙实底太刺眼，按钮多的页面尤其明显
- **一屏最想让人点的那一个用强调按钮**（亮橙实底、淡光晕）：首页首屏的登录与签到、`/launch` 的下载
- **全站可点击卡片用同一个模板**：图标底块、标题与说明、可选的操作胶囊、右侧圆形箭头
- **属性加点的图标换成柱状图**，头部菜单、首页卡片、个人主页入口卡三处一起换
- **技能与物品的功能色由橙换成蓝**：橙已经是网站主色
- **规范不画成图片**：开发环境加一个 `/design-system` 页，用真实 token 和组件渲染
- **中文多行文案按意思断行**：首页标题断成「DOTA2 10v10 AI / 自定义地图」

## 首页设计（PR 3）

**首屏**

- 背景是游戏封面图去掉标题文字的版本，手机上裁到 Dota 标志那一块，标题上移
- 标题「DOTA2 10v10 AI / 自定义地图」；副标题在「在 Steam 创意工坊订阅我们的地图，」之后断行
- 两个按钮：「获得地图」带 Steam 图标，「下载启动器」带播放图标。原来单独的创意工坊卡并进这里
- 头部导航与线上一致

**未登录的面板**：要一眼看出是示例，免得玩家以为自己已经登录、等级不对

- 标题「登录查看自己的数据」
- 虚线框的示例卡：标签「示例」、昵称「玩家昵称」，等级与进度用示例数字
- 下面一行小字「以上是示例，登录后显示你自己的等级和积分」
- Steam 登录用强调按钮，下面保留加速器提示与隐私说明

**已登录的面板**

- 头像、昵称、ID、会员状态，「个人主页」按钮
- 勇士、会员两块：大号等级、进度条、「距 N 级还差 X」、可用积分。进度取玩家接口已有的当前级与下一级积分，不多发请求
- 今日签到用强调按钮
- 不放单项属性与已觉醒数量

**首屏下方**

- 六张主要页面卡片，会员不再占一格
- 卡片下面一行：左边会员卡，右边启动方式卡
  - 会员卡：皇冠图标，「每月领会员积分，开局抽选技能升级为 8 选 1，还有会员专属 BUFF」，胶囊「查看会员福利」
  - 启动方式卡：标题「启动方式」，「用启动器开局，游戏更流畅、不卡顿，支持多人联机。」，胶囊「游廊和启动器，怎么选？」，橙色播放图标底块

## 不做

- 排行榜的总积分不显示：本来就是有意隐藏的
- 不引组件库，不改断点与内边距的写法
