# 批次 1：新框架迁移

> 状态：已完成。当前的技术方向见 [docs/web/README.md](../../web/README.md) 第 4 节。

拆成五次独立上线：清残留与移动端修复、Next 16、Tailwind 4 + 设计 token、去 antd、React 19。

## 决定

- **视觉风格这一批不换**，仍是原来的深色蓝：这样任何肉眼可见的变化都是回归
- **纯升级的 PR 不改页面，改页面的 PR 不升级**：混在一起，线上出差异分不清是升级带来的还是重写带来的。这条对后面每一批同样适用
- **`globals.css` 里的 `@apply` 类保留，不删**：它们是当时唯一把颜色收敛好的地方，删掉等于把颜色散回 JSX。要收拾的是 JSX 里散着的硬编码颜色类
- **接受 Tailwind 4 的浏览器门槛**（Safari 16.4+ / Chrome 111+）：玩家从游戏内跳到自己的浏览器打开，不经过 Dota2 内置的 CEF
