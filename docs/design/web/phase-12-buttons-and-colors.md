# 批次 12：按钮体系、交互色与登录等待

> 状态：设计中，四节各有推荐方案，待拍板。依赖批次 10 PR 2 与批次 11，在它们之后实现。

四件事的共同问题：**网站没有自己的一套控件语言**。默认按钮、交互色都借用了游戏的勇士紫，于是紫色既表示「勇士积分」又表示「能点」，每一页都满是紫；加载与退出这些网站独有的流程也没有专门设计。

## 1. 登录回调：不再整页遮罩

登录回调页只渲染 `Spinner`：`fixed inset-0` 盖一层 `bg-surface/85`，中间一个 48px 紫色转圈，「正在登录」只写在 `aria-label` 里。头部、底部被遮住，画面上没有任何文字。激活页提交时（`ManualActive`）用的是同一个组件。

**推荐方案 L1：头部照常显示，正文放一张步骤卡。**

- 卡片与 `Notice` 同宽（576px），与失败态放在同一个位置：成功直接跳走，失败原地换内容，不换布局
- 标题「正在登录」，一句说明「Steam 已经确认了你的身份，正在进入网站，完成后自动回到刚才的页面」
- 三步：Steam 确认身份 → 登录网站 → 回到刚才的页面。前两步对应代码里的 `verify` 与 `signIn` 两段，失败时玩家看得出卡在哪一步
- 超过 4 秒未完成（代码在退避重试），第二步后面补一句「网络有点慢，正在重试」
- 失败态：按 `Failure.stage` 分两套文案与按钮。`signIn` 失败：「再试一次」（重用手上的 token）；`verify` 失败：「重新登录」（重走 Steam）。都配一个「返回首页」文字按钮。错误码保留，小字等宽
- 转圈改用交互蓝，见第 4 节

方案 L2（未推荐）：不用卡片，只在正文中间放转圈加两行字。改动最小，但慢和失败时说不清卡在哪一步，失败态要换成另一套布局。

**头部不遮住。** 遮罩存在的唯一好处是挡住头部的「登录」按钮；登录中途点它只是重新走一遍 Steam，不会出错，不值得为此遮掉整页。

**激活页提交不再用整页遮罩**，改成提交按钮自己的「处理中」状态（按钮内 16px 转圈、保持宽度、禁用）。全屏 `Spinner` 两个使用方都换掉后删除。

## 2. 头部退出按钮

电脑宽度（≥ 1024）的账号控件是「人形图标 + ID」链接加一个 16px 退出图标，两者只隔 8px，退出的点击区只有 16 × 16，容易点偏进个人主页。

**电脑版菜单里没有「退出登录」是特意的**（phase-2g-header-layout.md）：电脑宽度退出已在账号控件里，菜单里藏掉免得两处重复；手机与平板的账号控件放不下退出，才挪进菜单。问题出在这个决定的代价上。

**推荐方案 H1：账号控件只留 ID，退出在所有宽度都放进菜单底部。**

- 账号控件整块是一个链接，点哪都进个人主页，不会点错
- 菜单底部的「退出登录」去掉 `lg:hidden`，全站只有一个退出位置
- 代价：电脑上退出多一步。玩家很少退出，可以接受

方案 H2（未推荐）：退出留在头部，拆成独立的 34 × 36 方块，中间加分隔线，悬停红底。一步就能退出，但头部多占约 26px（768 的横排导航本来就紧），退出仍然是两处。

## 3. 属性加点与英雄觉醒的图标颜色

同一个图标三处三种颜色：首页「主要页面」卡片 `text-muted`，头部菜单 `text-content`，个人主页入口卡 `text-season` 加紫色底块与紫箭头。

| 方案 | 属性加点 | 英雄觉醒 | 取舍 |
|---|---|---|---|
| 一 全中性 | `--color-content` | `--color-content` | 延续菜单「只有皇冠带色」；最稳，但更灰 |
| 二 青 + 橙 | `#31c8c9` | `#ec9c63` | 橙与会员金只差约 30°，手机单列时觉醒卡紧挨会员卡，易混 |
| **三 青 + 玫粉（推荐）** | `#31c8c9` | `#ea91bc` | 与现有紫、金、蓝、红、绿都拉得开 |
| 四 游戏紫 | `--color-season` | `--color-season` | 与游戏一致；紫更多，且属性点来自两种等级，不只勇士 |

候选色取 oklch(0.76 0.12 h)，只换色相，对 `--color-panel` 对比度 8.4–9.4 : 1。已占用的色相：危险红 21°、会员金 84°、成功绿 144°、链接蓝 246°、勇士紫 302°；青 195° 与玫粉 350° 落在空隙里。

用法约束（方案二、三）：

- **颜色只上图标与图标底块**（底块同色 12% 透明度），数值、按钮、标题、箭头都不跟；箭头一律 `--color-muted`
- 三处统一：首页卡片、头部菜单、个人主页入口卡用同一个颜色
- 「即将上线」只靠虚线描边、灰标题与标签表达，图标颜色不变
- 新增 token `--color-property`、`--color-awaken` 及各自的 `-soft`，不在调用点写色值

采用方案二或三时，phase-7-visual-style.md 第 5 节「只有皇冠带色」要改写：当时头部只有文字导航，图标只为区分菜单行；首页与个人主页出现成排的入口卡后，同一个功能在三处颜色一致，比全灰更好认。

## 4. 按钮体系与交互色

### 现状

- 公共 `Button` 的默认 `variant` 是 `season`，即游戏的紫色渐变；会员页订阅、激活结果都用它。激活页提交用会员金
- 交互反馈全部是紫：头部当前页下条、菜单当前页竖条、`card-hover`、焦点框 `outline-accent`、转圈 `text-accent`
- 游戏的 `buttons.less` 本来就分主按钮（紫）、金、镂空（ghost）、灰色禁用四档；网站只照搬了紫和金

### 规则

**按钮颜色回答「点了花什么」，不回答「这一页讲什么」。**

| 操作 | 按钮 |
|---|---|
| 花勇士积分，或与游戏里是同一个操作（加点、觉醒） | 勇士紫渐变 `.btn-season`，暂存一步用 `.btn-season-outline` |
| 花会员积分 | 会员金渐变 `.btn-member` |
| 其余：提交、重试、跳转、去外部平台订阅 | 网站主按钮 |

外观上也分得开：**纯色是网站的，渐变是游戏的。** 游戏按钮取值照搬 `buttons.less`，不变。

「会员相关就用金」不成立：会员页、激活页都跟会员有关，全用金就是把现在紫色的问题换成金色再来一遍。

### 网站按钮

| 变体 | 默认 | 悬停 | 按下 | 用在 |
|---|---|---|---|---|
| 主按钮 | 底 `#2266a4`、边 `#3b7fc0`、白字 | 底 `#2b73b6`、边 `#4b8dcc` | 底 `#1d5a92` | 每屏最多一个：提交、重试、订阅 |
| 次按钮 | 底 `--color-control`、边 `--color-line`、字 `--color-content` | 底 `--color-control-hover`、边 `#3f3f46`、字 `--color-heading` | 底 `#141416` | 登录、取消、次要操作 |
| 文字按钮 | 透明、字 `--color-content` | 底 `--color-panel-soft`、字 `--color-heading` | 底 `#141416` | 返回、跳过，与主按钮并排 |
| 危险按钮 | 边 `danger/50`、底 `danger/8`、字 `--color-danger` | 底 `danger/15` | 底 `danger/22` | 重置这类撤不回的入口 |

共同规格：14px / 700、无文字阴影；圆角 7px；高度沿用手机与平板 44、电脑 40；大号 56（登录横幅、登录面板）；头部 36。焦点框 2px `--color-link`、偏移 2px。禁用一律灰底灰字 `#5d5d66`。处理中：按钮内 16px 转圈，文字换成「提交中」这类进行时，宽度不变，同时禁用。

主按钮白字对 `#2266a4` 对比度 6.0 : 1，悬停态 5.1 : 1，都过 AA。

**推荐方向 A「功能蓝」**：蓝已经是网站的链接色，主按钮沿用，含义一致；与紫、金一眼分开。代价：Ko-fi 品牌色也是蓝，会员页上两者同屏，靠平台卡标题的品牌色区分。

方向 B「中性白」（未推荐）：白底黑字，对比度 19 : 1，不给颜色加含义。但深色页面里一块纯白非常抢眼，和游戏渐变按钮同页（重置弹窗）时风格割裂最明显。

### 现有按钮的归属

| 位置 | 现在 | 改成 |
|---|---|---|
| `Button` 默认 `variant` | `season` | 主按钮 |
| 会员页爱发电 / Ko-fi 订阅 | `.btn-season` | 主按钮 |
| 激活页提交 | `.btn-member` | 主按钮 |
| 激活结果「返回首页」「重试」 | `Button` 默认紫 | 主按钮 |
| 登录失败 | `steam` 变体，文字「请稍后重试」 | 主按钮「再试一次」/「重新登录」+ 文字按钮「返回首页」 |
| 登录入口、创意工坊订阅 | Steam 灰 | 次按钮 + Steam 图标，外观不变 |
| 属性页升级、暂存 | 紫渐变 / 紫描边 | 不变 |
| 属性页「重置属性」 | 红描边 | 危险按钮，外观不变 |
| 重置弹窗 | 紫 / 金 / 灰「取消」 | 不变 / 不变 / 次按钮 |
| 觉醒页解锁（未做） | — | 花勇士积分用紫，花会员积分用金 |

「请稍后重试」是提示不是动作，不再用作按钮文字。

### 交互色从紫换成蓝

| 位置 | 现在 | 改成 |
|---|---|---|
| 头部横排当前页下条、菜单当前页竖条 | `--color-season-strong` | `--color-link` |
| `card-hover` | `--color-season-border` | `--color-link` 40–45% 透明度 |
| 焦点框 | `--color-accent` | `--color-link` |
| 转圈 | `--color-accent` | `--color-link` |

保留紫：勇士等级与积分的数值、进度条；属性卡进度条与加点按钮；勇士相关页面标题。批次 11 属性页等级框的悬停仍按货币色（勇士紫、会员金），不用 `card-hover`。

`--color-accent` 系列当初为了「写了 `text-accent` 的组件不用改」指向勇士紫；交互色换成蓝后，这层别名只会让人误以为 accent 是紫，实现时改名或删掉，调用点改用明确的 token。

## 5. 不做

- **不改游戏按钮的取值**。属性、觉醒页要与游戏内同名操作长得一样
- **不引组件库**。四种网站按钮仍是 `globals.css` 的几个类加 `Button` 的变体
- **不给「每日任务」「技能与物品」定图标颜色**，页面上线时再按第 3 节的方式挑
