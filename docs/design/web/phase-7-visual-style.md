# 批次 7：视觉风格

> 状态：已完成。长期规范见 [docs/web/design-system.md](../../web/design-system.md)（配色、按钮、可点击元素与当前页标记）与 [web/CLAUDE.md](../../../web/CLAUDE.md)（颜色、按钮、内边距）。

网站此前直接沿用迁移期的深色蓝，颜色没有分工，字体与组件规格也没定。这一批定下 token 取值、字体与基础组件的样子，不重构组件。

## 决定

- **紫与金只表示勇士与会员两套货币**：取自游戏内的 season point 色与 `@color-gold`，玩家在两边认得出同一套积分
- **标题跟着内容的归属着色**，不是一律白也不是一律金：game 里标题一律金，但金在网站已经等于会员，全站变金会让金皇冠和金订阅按钮失去识别作用；一律白则层级只剩字号一档
- **链接单开一档蓝**：链接是功能、与归属无关，用紫会被读成跟积分有关
- **赞助平台的品牌色只上平台名与指向该平台的链接**，不上按钮：爱发电紫离勇士紫只差一点，铺开就分不清是积分还是平台
- **游戏按钮的取值照搬 game 的 `buttons.less`，不改**：属性、觉醒页要与游戏内同名操作长得一样
- **禁用态换成灰底灰字，不是降透明度**：金底降一半仍看得见字，紫底会糊
- **登录按钮保持中性灰**：紫和金是货币色，Steam 入口染上任何一种都会被读成跟积分有关；它靠 36px 高度和最右位置已经够显眼
- **菜单图标只有皇冠带色**：图标是让人扫一眼认出哪一行的，四个都上色反而找不到东西
- **内边距按宽度收放，收进三个类**：页面、卡片、嵌入块三层留白在 375 叠加到单边 56px，正文只剩 263px；桌面上这三层又是必要的呼吸感，所以不是统一调小
- **字体只留 Noto Sans SC**：中文本来就落到系统字体，Inter 只多一次请求；中文衬线体积大、气质也不像游戏界面，层级靠字号和颜色已经分得开

## 不做

- 不引组件库，也不重构组件——头部刚在 #1161 重做完，这一批的范围是只改取值
- 横排不做滑动指示器：桌面横排当时只有「会员」一项可见
- 行为分分段色留到战绩组件接入时再做

## 后续事项

- `.btn-member`、`.btn-afdian`、`.btn-kofi` 的白字在渐变亮端低于 WCAG AA，为保持游戏内按钮风格继续使用白字
- Tooltip 要用成熟组件库实现，需覆盖视口避让、触屏、键盘焦点与滚动跟随
