# 批次 3b-2：觉醒技能提示框

> 状态：已完成。长期规范见 [docs/web/ability-tooltip.md](../../web/ability-tooltip.md)。

觉醒卡悬停时只有一行 11px 的技能名，看不清；详情弹窗只有描述，游戏里能看到的数值、冷却、耗蓝都没有。

## 决定

- **悬停弹出 Dota 式技能提示框，取代卡面上的小字**：玩家在游戏里就是这样看技能的
- **详情弹窗放同一份技能块**：触屏没有悬停，数值只能在弹窗里看到
- **已觉醒在标题旁与付费按钮位置两处都标**：状态跟技能名一起被看到
- **弹窗文案精简**：「已觉醒，每局自动生效」改成「已觉醒」，删掉与规则区重复的「永久觉醒不可撤销」
- **数据结构参考 OpenDota，组件自己写**：理由见长期规范第 6 节

## 不做

- 不展示天赋、神杖、魔晶加成与 Note：游戏内的悬停提示也不展示
- 触屏不做长按出提示：点卡片进详情，数值一样在
- 不高亮当前等级：网站上没有「当前等级」

## 后续事项

- 几处 game 仓库里找不到依据、按判断先实现的显示规则待对照游戏截图确认：只显示一种技能类型时的优先级、技能增强数值按伤害类型上色、物理伤害色 `#ae2f28`、不显示「能否破坏」
- wiki 的技能与物品页复用同一套组件与取数规则
- 按最终取值画一张规范画板，放 `docs/web/images/ability-tooltip/`
