# 批次 3b-2：觉醒技能提示框

> 状态：已完成。长期规范见 [docs/web/ability-tooltip.md](../../web/ability-tooltip.md)。

觉醒卡悬停时只有一行 11px 的技能名，看不清；详情弹窗只有描述，游戏里能看到的数值、冷却、耗蓝都没有。

## 决定

- **悬停弹出 Dota 式技能提示框，取代卡面上的小字**：玩家在游戏里就是这样看技能的
- **箭头对着卡片上部，不对准技能图标**：提示框属于整张卡，位置固定更简单
- **详情弹窗放与提示框同一份技能块**：触屏没有悬停，数值只能在弹窗里看到；两处共用一个组件，不写两份
- **已觉醒两处都标**：标题右侧放徽章，付费按钮的位置放同高的状态条。徽章让状态跟技能名一起被看到，状态条与卡片底部的「已觉醒」同位置同样式
- **文案「已觉醒，每局自动生效」改成「已觉醒」**
- **删掉「永久觉醒不可撤销」**：规则区已经写了
- **提问改成「选择消耗的积分，觉醒该英雄」**：原句的「永久」与规则区重复，问号语气也别扭
- **修掉同步产物里的 `%%`**：game 用 `%%` 转义百分号，同步脚本只替换了占位符、没还原转义，有 10 处描述显示成「80%%」
- **属性的标签文案放网站 i18n，措辞照抄 Dota**：Dota 的 `dota_*.txt` 只在旧版本参考目录里有，跟着版本目录取会断；这几十个词也不随版本变
- **KV 改用保序的解析器，不再用正则摊平**：数值行要保留顺序和同块标记（范围加成、技能增强），正则摊平会把天赋加成键混进数值
- **数据结构参考 OpenDota，组件自己写**：理由见长期规范第 6 节

## 不做

- 不展示天赋、神杖、魔晶加成与 Note：游戏内的悬停提示也不展示
- 触屏不做长按出提示：点卡片进详情，数值一样在
- 不高亮当前等级：网站上没有「当前等级」
- 描述里多级数值的占位符仍按 KV 原样的空格分隔：与 `%%` 无关，改显示格式要先对照游戏
