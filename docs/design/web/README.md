## 子文档写什么

每份子文档在开工前写，内容限于该批次：

- 目标与验收标准
- 涉及的接口与鉴权改动（新增路由、装饰器、白名单）
- 页面与组件清单
- 测试清单（unit / e2e / 线上验证）
- 该批次内需要拍板的技术选择

批次上线后整篇删除，删之前按 [design-docs](../../../.claude/skills/design-docs/SKILL.md) 技能把至今仍然生效的规则与约束并进 `docs/web/`，还没做的后续事项转成 issue。
