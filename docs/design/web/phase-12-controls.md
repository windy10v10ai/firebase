# 批次 12：按钮体系、登录等待与头部退出

> 状态：已完成。按钮与等待的长期规范见 [docs/web/design-system.md](../../web/design-system.md)。

## 决定

- **网站补上主、次、文字、危险四档按钮，渐变只留给花积分的操作**：默认按钮原本就是游戏紫渐变，会员页、激活页全被染成紫
- **登录回调不盖整页遮罩，改成步骤卡**：等待超过 4 秒显示已等时长，15 秒给出重试，失败给一块可截图的排查信息。玩家常在转圈时就关掉页面，排查信息只放在失败页不够
- **失败原因按 Firebase SDK 错误对象的 message 细分**：SDK 把超时、连不上、响应解析失败报成同一个 `auth/network-request-failed`，且单个请求 30 秒才超时、不能配置
- **头部退出暂定为独立方块，菜单里也放退出**：原本 16px 图标紧挨 ID，容易点偏；两处都放是为了开发期间反复登录测试方便，之后可以只留菜单里那个

## 不做

- 不改游戏按钮的取值
- 不引组件库
