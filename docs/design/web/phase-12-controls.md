# 批次 12：按钮体系、登录等待与头部退出

> 状态：已完成。按钮规范与截图见 [docs/web/design-system.md](../../web/design-system.md)，本文只留取舍过程。登录等待采用 L1；头部退出暂定 H2。

## 1. 登录回调：不再整页遮罩

登录回调页原本只渲染一个全屏 `Spinner`：盖一层 85% 的遮罩，中间一个紫色转圈，「正在登录」只写在 `aria-label` 里，头部、底部都被遮住。激活页提交用的是同一个组件。

**采用 L1：头部照常显示，正文放一张步骤卡。** 卡片与 `Notice` 同宽，与失败态在同一个位置：成功直接跳走，失败原地换内容。三步「Steam 确认身份 → 登录网站 → 回到刚才的页面」，前两步对应代码里的 `verify` 与 `signIn`，失败时看得出卡在哪一步。失败按 `Failure.stage` 分两套：`signIn` 失败「再试一次」（重用手上的 token），`verify` 失败「重新登录」（重走 Steam）。

L2（未采用）：只在正文中间放转圈加两行字。改动最小，但慢和失败时说不清卡在哪一步，失败态还要换成另一套布局。

**头部不遮住。** 遮罩唯一的好处是挡住头部的「登录」按钮；登录中途点它只是重新走一遍 Steam，不会出错。

**激活页提交改成按钮自己的处理中状态**，全屏 `Spinner` 删除。

### 等待与失败时给出排查信息

玩家「等不了」多半发生在转圈期间，失败页还没出现就关掉了，所以排查信息在等待中就要看得到：

- **超过 4 秒**：当前步骤后面显示已等秒数与第几次尝试
- **超过 15 秒**：出现次按钮。第二步卡住时「再试一次」并行开一轮新的登录，不打断正在进行的请求，谁先成功就跳走；第一步卡住时「重新登录」直接回 Steam
- **失败**：一块等宽小字写明卡在第几步、错误码与细分原因、尝试次数、总耗时、发生时间（带时区）、玩家 ID。玩家 ID 由 Steam 回调参数里的 64 位 ID 换算，第一步失败也拿得到；时间与 ID 用来在生产日志里找到同一次登录

只看错误码分不出原因，需要细分：

| 情况 | 原本显示 | 改成 |
|---|---|---|
| 第一步 `fetch` 被拒（连不上接口、跨域失败） | `unknown` | `network` |
| 第一步接口一直不响应 | 无限转圈，没有错误 | 加 20 秒超时，显示 `timeout` |
| 第二步 SDK 超时 | `auth/network-request-failed` | 同码，细分「超时」：错误对象的 `customData.message` 为空 |
| 第二步连不上代理 | 同上 | 细分「连不上」：message 含 `Failed to fetch` |
| 第二步代理返回错误页 | 同上 | 细分「返回的不是 JSON」：message 是 JSON 解析错误 |

Firebase Auth SDK 每个请求在浏览器里超时 30 秒，超时、`fetch` 被拒、响应解析失败一律报 `auth/network-request-failed`。第二步有两个请求（`accounts:signInWithCustomToken` 与 `accounts:lookup`），加两次重试，最坏要 1.5–3 分钟才出失败页。SDK 的超时不能配置，所以靠显示已等时长、提前给出重试按钮，而不是去缩短超时。

## 2. 头部退出按钮

电脑宽度的账号控件原本是「人形图标 + ID」链接加一个 16px 退出图标，两者只隔 8px，退出的点击区只有 16 × 16，容易点偏进个人主页。电脑版菜单里没有「退出登录」是 phase-2g 特意的：电脑宽度退出已在账号控件里，菜单里藏掉免得重复。

**暂定 H2，菜单里也放退出。** 开发期间要反复登录退出测试，一步就能退出更方便。电脑宽度退出拆成独立的方块，与 ID 之间加分隔线，悬停红底；菜单底部的「退出登录」所有宽度都显示。代价是头部略宽，768 的横排导航本来就紧。

H1（暂不采用）：账号控件只留 ID，退出只放菜单底部。全站只有一个退出位置、不会点错，但电脑上退出多一步。测试需求过去后可以切到 H1。

## 3. 按钮体系

网站原本只照搬了游戏的紫、金两种渐变按钮，默认按钮就是紫渐变，会员页订阅、激活结果、表单提交都成了紫色；而游戏的 `buttons.less` 本来就分主按钮、金、镂空、灰色禁用四档。于是补上网站自己的主、次、文字、危险四档，渐变只留给花积分的操作。选型规则与规格见 design-system.md。

## 4. 不做

- **不改游戏按钮的取值**。属性、觉醒页要与游戏内同名操作长得一样
- **不引组件库**。四种网站按钮是 `globals.css` 的几个类加 `Button` 的变体
