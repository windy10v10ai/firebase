# 批次 3b-3：觉醒详情弹窗与随机卡的折扣显示

> 状态：已完成。长期规范见 [docs/web/ability-tooltip.md](../../web/ability-tooltip.md) 第 3、4 节，折扣色见 [docs/web/design-system.md](../../web/design-system.md)「状态色」。

技能说明长的英雄，手机上付费按钮被挤出屏幕；电脑上弹窗高度随英雄变，按钮位置跟着跳，想点关闭容易点到付费，而付费点下去就直接扣积分。随机抽选的半价只写在一行小字里，随机卡的整块紫底又和勇士积分的紫撞色。

## 决定

- **手机用贴底抽屉，平板起居中且统一高度**：两边的按钮位置都不随英雄变。没选「只让按钮吸底」，电脑上短技能的按钮仍会跳；没选电脑也底边对齐，短技能的弹窗会偏下
- **说明放不下时电脑直接滚动，触屏先收起、点「详细」才滚动**：电脑有滚轮，多点一次反而麻烦；触屏第一眼不出滚动条
- **电脑弹窗高度保持 640**：调高能让收起的英雄变少，但短技能下面的空白跟着变大，电脑改成直接滚动后收益不大
- **关闭挪到右上角 ×**：离付费按钮最远
- **手机抽屉加从头部下拉关闭**：× 仍是主要关闭方式，下拉只是补充；只认头部，不和说明区的滚动抢手势
- **随机半价在付费按钮上划掉原价，删掉「随机抽选消耗积分减半」那句**：价格变化落在要点的按钮上
- **随机卡换成压暗的立绘拼贴底，标题旁加「-50%」标签，保留金色描边**：立绘铺底和英雄卡一致，三张立绘本身在说「从这些里抽」；标签和限免标签同形，网站不另发明写法
- **折扣标签用新的红色 token，不用绿色也不借 danger**：绿色已经是限免，两个标签会分不清；折扣也不是危险

## 不做

- 付费不做「点两次才扣分」：按钮位置固定后误点的根子已经没了，每次觉醒多一步不值
- 折扣不写进抽选按钮：按钮 30px 高，手机两列时字挤
- 随机卡背景不做立绘轮换动画：网格里只有它在动，太抢眼
- 属性页的重置弹窗、随机候选弹窗不跟着改：内容短，放得下
