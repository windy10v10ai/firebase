# 批次 3b-3：觉醒详情弹窗的高度与半价显示

> 状态：已完成。长期规范见 [docs/web/ability-tooltip.md](../../web/ability-tooltip.md) 第 3、4 节。

技能说明长的英雄，手机上付费按钮被挤出屏幕；电脑上弹窗高度随英雄变，按钮位置跟着跳，想点关闭容易点到付费，而付费点下去就直接扣积分。

## 决定

- **手机用贴底抽屉，平板起居中且统一高度**：两边的按钮位置都不随英雄变。没选「只让按钮吸底」，电脑上短技能的按钮仍会跳；没选电脑也底边对齐，短技能的弹窗会偏下
- **说明放不下时先收起，点「详细」才滚动**：第一眼不出滚动条；展开时自动滚到被渐隐盖住的地方，点了有看得见的变化
- **关闭挪到右上角 ×**：离付费按钮最远
- **随机半价在按钮上划掉原价，删掉「随机抽选消耗积分减半」那句**：价格变化落在要点的按钮上，不用再读一行说明

## 不做

- 付费不做「点两次才扣分」：按钮位置固定后误点的根子已经没了，每次觉醒多一步不值
- 抽屉不做下滑关闭：×、Esc、点遮罩已经够用
- 属性页的重置弹窗、随机候选弹窗不跟着改：内容短，放得下
