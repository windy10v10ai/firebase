# 批次 12：配色体系

> 状态：已完成。最终规范（分工、取值、截图）见 [docs/web/design-system.md](../../web/design-system.md)，本文只留取舍过程。

**要解决的问题**：紫色同时是勇士积分色、全站交互色（当前页下条、菜单竖条、卡片悬停、焦点框、转圈）和默认按钮色，每一页都满是紫，玩家分不清哪块紫在说积分、哪块在说「能点」。结论是每种颜色只管一件事，交互色与默认按钮换成网站自己的主色。

## 主色：五个方案里选电光蓝

| 方案 | 按钮 | 文字对比度 | 撞色 | 评价 |
|---|---|---|---|---|
| 功能蓝 | `#2266a4` 纯色、白字 | 6.0 : 1 | 无 | 稳，但暗、平 |
| **电光蓝（采用）** | `#2563eb` 纯色加底部光晕、白字 | 5.2 : 1 | Ko-fi、支付宝，品牌色只在标识上，不同处出现 | 亮、有网站自己的质感，和游戏渐变一眼分开 |
| 中性白 | `#fafafa`、黑字 | 19 : 1 | 无 | 深色页面里最抢眼；与游戏渐变按钮同页时割裂最明显 |
| 冰川青 | `#22d3ee`、深字 | 8.8 : 1 | 每日任务青、Ko-fi | 活泼，但每日任务要换色 |
| 薄荷绿 | `#34d399`、深字 | 7.7 : 1 | 成功绿、微信支付 | 游戏感最强，但「绿 = 成功」已被占用 |

比较时在线上会员页与首页注入覆盖样式，逐一看头部当前页下条、订阅按钮与卡片悬停，而不是只看色块。

链接色原本是 `#6aa9e0`，与主色标记档 `#60a5fa` 并存会出现两种蓝，统一成后者。`--color-accent` 系列原本指向勇士紫，交互色换掉后这层别名只会误导，删除。

## 功能色：从「只有皇冠带色」到每个功能一个颜色

同一个图标原本三处三种颜色：首页灰、头部菜单白、个人主页紫。比较过四套：

| 方案 | 取舍 |
|---|---|
| 全中性，只有皇冠带色 | 最稳，但页面更灰，和「颜色太少」的反馈相反 |
| 属性青 + 觉醒橙 | 橙与会员金只差约 30°，手机单列时觉醒卡紧挨会员卡，易混 |
| 属性青 + 觉醒玫粉 | 与已有颜色都拉得开，但与游戏内两个功能的主色无关 |
| 属性、觉醒都用游戏紫 | 与游戏一致，但紫更多，且属性点来自两种等级，不只勇士 |

**最终**：思路取「各自分开」，颜色向游戏靠拢——属性用勇士紫，觉醒参考游戏的 `#d000ff`。`#d000ff` 本身离勇士紫只差 15° 色相、饱和度拉满，缩成 20px 图标后两者都读成紫，对比度只有 4.7 : 1，所以往粉偏到 325°、亮度与勇士紫相当，取 `#dd53e7`；更安静的 `#df63e8` 未采用。每日任务、技能与物品与两个预留色按同一亮度往色环空隙里排，避开带含义的色相。

当初「只有皇冠带色」是因为头部只有文字导航，图标只为区分菜单行；首页与个人主页出现成排的入口卡后，同一个功能三处同色比全灰更好认。

## 品牌色：只上标识

爱发电、Ko-fi、支付宝、微信支付的品牌色分别与勇士紫、主色蓝、成功绿同色系。原先会员页有过赞助平台各自的渐变按钮（`.btn-afdian`、`.btn-kofi`），按「只上标识」的规则删除；平台名与激活页标题保留品牌色。

## 不做

- **不改游戏按钮的取值**
- **不引组件库**
