# 每日任务英雄 Metric、技能与 Target 审计

日期：2026-08-15

## 结论摘要

- 审计范围：127 个英雄、245 条英雄任务。
- 建议直接删除或替换：27 条。
- 建议先实测 `GetStuns()` / `GetHealing()` 口径再决定：6 条。
- 建议新增或替换 metric：39 个英雄。
- 当前 `target` 已改为 **1★ 基础值**；2★ / 3★ 使用 `1 / 1.5 / 2`，小整数使用加法档。本文建议值均为 1★。
- 建议 target 是上线前的技能与定位估值，不替代 #1057 的 BigQuery 分英雄标定。
- 已对全部 53 条建议保留的 `stun_duration` 重新估值：多技能、长时间小技能、范围和重复命中会提高 target。

### 判断口径

- `stun_duration`：以实机统计结果为准。已确认祸乱之源睡眠、蝙蝠骑士枷锁、百戏大王恐惧、娜迦海妖网和拉比克举都计入；娜迦海妖大招睡眠和虚无之灵牵引不计入。
- `healing`：优先认可直接治疗英雄的技能；被动生命恢复、吸血、生命交换和只治疗非英雄单位的效果不默认视为有效。
- `hero_damage` / `damage_taken`：按英雄核心、爆发、前排、机动等定位评估，不要求某个单独技能完成。
- 每个英雄原则上最多保留 2 个 metric；三任务英雄先删通用性更强或与定位重复的一项。
- 本文沿用上一轮人工筛选作为约束：不重新添加已明确删除的开膛手杰克 healing 或谜团 stun_duration；蝙蝠骑士按人工确认保留 tower_kills。
- target 优先使用偶数，确保乘以 1.5 后仍为整数。

### `stun_duration` target 重新分档

| 1★ target | 适用情况 | 典型特征 |
|---:|---|---|
| 20～40 | 低频、极短或主要依赖长冷却技能 | 单体、累计效率低 |
| 50～70 | 一个可稳定循环的常规控制 | 时长或冷却至少有一项较优 |
| 80～100 | 多个控制技能、长时间小技能或稳定范围控制 | 同一次施法可对多名英雄累计 |
| 120 | 多技能且可反复命中多人的强控英雄 | 高频、范围、重复触发同时存在 |

估值时使用“可计入的控制时长 × 可靠施放频率 × 预期命中英雄数”，而不是只看技能数量或大招时长。所有建议值仍低于通用任务的 150。

装备驱动的特例：修补匠基础技能没有眩晕，但再装填可刷新控制道具，因此可用 `stun_duration` 60 替换无法完成的 `healing`。

## Target 建议档位

| metric | 建议 1★ 档位 | 依据 |
|---|---:|---|
| `hero_damage` | 250,000～550,000 | 辅助/前排取低档，高成长 Carry/Nuker 取高档 |
| `damage_taken` | 400,000～600,000 | 按 Durable、先手频率和减伤/回复能力分档 |
| `healing` | 40,000～80,000 | 按单次治疗、冷却、范围和是否可持续施放分档 |
| `stun_duration` | 20～120 秒 | 按可计入的技能数量、控制时长、冷却、范围和重复命中能力分档 |
| `assists` | 60～80 | 按辅助、范围伤害和先手能力分档 |
| `kills` | 32～50 | 按收割、爆发和核心定位分档 |
| `tower_kills` | 8～14 | 只保留有召唤物、建筑伤害、推塔型先天技能或明确推进能力的英雄 |
